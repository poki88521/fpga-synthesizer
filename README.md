# FPGA 合成器 · 网页工具

三个纯前端页面，用来调试和试听这台 FPGA 合成器。**无构建、无依赖、不联网**。

| 页面 | 干什么 |
|---|---|
| `index.html` | MIDI 串口调试器：连上板子发消息、听声音、查指令对不对 |
| `mixer.html` | 独立混音台：16 通道的音量/声像/音色 |
| `timbre.html` | 音色渲染器：在电脑上按 FPGA 的算法试听 8 个音色 |

---

## 启动

**双击 `run.bat`**，然后打开 <http://127.0.0.1:8000/>。

`run.bat` 就一行：

```
D:\anaconda\python.exe -m http.server 8000 --bind 127.0.0.1 --directory <本目录>
```

> 必须走 `http://127.0.0.1` 或 https。**直接双击 html 用 `file://` 打开不行** ——
> 浏览器只在安全上下文里给 Web Serial 权限。
> 浏览器必须是 **Chrome / Edge**，Firefox 和 Safari 没有 Web Serial。

---

## 接线

| USB-TTL | FPGA |
|---|---|
| **TX** | MIDI 输入脚 |
| **GND** | GND（必须共地） |
| 电平跳线 | **3.3V**（5V 会打坏 IO） |

引脚已定：**乐器口 C21**、**混音口 A17**。

两个口的区别：**混音类 CC（7 / 10 / 91 / 93 / 94）只有在混音口上才生效**，
乐器口会被固件主动丢弃。面板 2 选的口型要和实际接线一致。

## 一、调试器 `index.html`

14 个面板，顶部分类栏可按类筛选（连接 / 演奏 / 调制 / 指令 / 混音）。

| 面板 | 用途 |
|---|---|
| 1 · 串口连接 | 连/断 USB-TTL，31250 8N1 |
| 2 · 端口与通道 | 选乐器口/混音口，选 MIDI 通道（1–16） |
| 3 · 音色选择 | Bank Select + Program Change，8 个音色一键切 |
| 4 · 表情与滤波 | 弯音、CC1/11/71/72/73/74、延音踏板 CC64 |
| 6 · 音符 | 音符/力度/和弦齐发，按住/松开 |
| 7 · 正在发声 | 页面自己记的"发过哪些 Note On 还没关" |
| 8 · 音符序列 | 批量音阶/琶音，可循环、可扫力度 |
| 9 · 手动十六进制 | 直接敲字节，逃生舱 |
| 10 · 指令检查 | 每条消息发送前按固件能力校验，发错当场标红 |
| 11 · 一键演示 | 整场过一遍 |
| 12 · ADSR 包络 | 按 RTL 参数推算的包络图 |
| 13 · 预设 | 把这一屏设置存到 localStorage / 文件 |
| 14 · 杂项 | CC120/CC123、效果参数 SysEx、主音量 SysEx |
| 15 · 混音台 | 16 通道总览（4 通道一页），点行切换 |

**两个要记住的点：**

1. **看不见设备状态。** FPGA 的 4 路 UART 全是接收，没有回传通道。
   声部分配、包络实际值、真实音量都读不回来 —— 页面显示的是"我发过什么"。
2. **面板 10 是安全网。** 它按 `midi_filter.v` / `chan_table.v` 的实际能力校验每条消息，
   比如"乐器口发 CC7"会被标成问题（只提示、不拦）。

## 二、混音台 `mixer.html`

独立的 16 通道混音页：一列通道 × 音色 + 音量/声像/表情/混响/合唱/延迟。

- 点任意一行切换编辑目标
- 音色用下拉（发 Program Change），其余用滑杆（发 CC，拖动中实时发送）
- 底部有「全部音量/全部居中/全部表情/全部效果」和 CC120 / CC123

> 和 `index.html` 的面板 15 是同一套模型，但**串口只有一份** —— 两个页面同时开会抢端口。
> 平时用 `index.html` 里的面板 15 就够，这个独立页适合单独开着调混音。

## 三、音色渲染器 `timbre.html`

在电脑上按 **FPGA 的算法**（DDS + 线性插值 → Chamberlin SVF → ADSR → VCA）
离线渲染音色，直接播放或导出 WAV。**不用综合 FPGA（一轮 1~1.5 小时）**。

- 8 个槽，每个槽可调：截止 f、谐振 q、起音 a、衰减 d、持续 s、释放 r、音量 vca、滤波型、包络曲线
- 参数框支持十进制和 `0x` 十六进制
- 「试听」播 C4、力度 100；「A/B 对比」8 个音色依次播；「导出 WAV」48 kHz / 16 bit / 单声道
- 下面画包络曲线和波形

依赖同目录的 **`wave_table.hex`**（8 槽 × 2048 点）。

## 已知限制

- **无回读**：页面状态是"发过的"，不是"板子上的"
- **乐器口丢弃 CC7/10/91/93/94**：混音类只能走混音口
- **主音量 SysEx 只有 8 档**：固件只取 14 位值的高 3 位（每档 6 dB）
- **CC66 sostenuto 是空壳**：字段存在但没接到声部层，发了没效果
- **音色切换对正在响的音无效**：只影响之后新起的音符
