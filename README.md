# MIDI 串口调试器

给本项目 FPGA 合成器用的 **MIDI 串口调试器**：浏览器里连 USB-TTL，按 31250 baud 8N1
往 FPGA 的 MIDI 输入发消息，用来听音色、试音高、扫力度。

单文件网页（`index.html`），无构建、无依赖、不联网。

> 交互形态参考了 [Conductance-lab/SerialWeb](https://github.com/conductance-lab/SerialWeb)
> （网页串口调试与图形解析工具），但**代码是干净重写的**，没有使用其源码 ——
> SerialWeb 是 AGPL-3.0，直接改会把本项目也卷进 AGPL。这里只借鉴了「网页串口工具」这个形态。

---

## 现在能用到什么程度

**FPGA 侧的 MIDI 接收链路已经全部实现**：4 路 `midi_parse` + `midi_arb` + `midi_filter` +
调度层（32 复音、8 音色槽、CC 实时调制、三种效果器、弯音、颤音）。上板实测过音高、音色、力度、
滤波器、效果器、32 复音 —— 具体进度见 `develop/scratch/agent/赛题完成进度表.md`。

所以这个调试器：

- ✅ 能连 USB-TTL、能发字节、**能真的听到声音**
- ✅ 每条消息发送前会按固件实际能力校验一遍（面板 10），发错了当场红字告诉你为什么
- ✅ 有 8 个音色、弯音、11 个 CC、效果器开关、和弦齐发、一键演示、包络图、预设
- ❌ **看不到设备状态**：FPGA 侧 4 路 UART 全是接收，没有回传通道。
  声部分配、`env_state`、实际音量这些网页读不到 —— 面板 13 的包络图是**按 RTL 参数算的**，不是读回来的

## 一、最快上手（照这个做）

### 第 0 步：确认浏览器

用 **Chrome** 或 **Edge**。Firefox / Safari 没有 Web Serial，用不了。

### 第 1 步：接线

| USB-TTL 一侧 | FPGA 一侧 |
|---|---|
| **TX** | → FPGA 的 **MIDI 输入脚**（接收脚） |
| **GND** | → FPGA 的 **GND**（必须共地） |
| 电平跳线 | 拨到 **3.3V**（5V 会打坏 IO） |

> 引脚**已经定了**：乐器口 **C21**（PMOD2_IO0）、混音口 **A17**（PMOD2_IO3）。
> 混音类 CC（7 / 10 / 91 / 93 / 94）只有接在混音口上才生效，详见 [§三](#三接线细节)。

### 第 2 步：双击 `start.cmd` 启动

打开文件管理器，进到 **`test_web\`**，**双击 `start.cmd`**。

会出现：

1. 一个**黑窗口**，里面显示服务地址（类似 `http://127.0.0.1:8000/`）
2. **浏览器自动打开**调试器页面

黑窗口里应该能看到这一行，看到它才算起来了：

```
  [OK] 服务已就绪
  用 Chrome / Edge 打开： http://127.0.0.1:8000/
```

> 脚本是**等服务真正能应答之后才开浏览器**的。如果服务起不来，
> 它会把 **Python 的原始报错**打印出来并停住等你按回车，**不会**给你开一个打不开的页面。

> **这个黑窗口要一直开着。** 关掉它 = 停服务，页面就连不上了。
> 想停服务：在黑窗口里按 `Ctrl+C`，或直接关窗口。

### 第 3 步：在页面里连串口

连串口的是**浏览器**，不是这个网页 —— 所以点完按钮会弹出一个**浏览器自己的对话框**，
那个框不属于本页面，长什么样由浏览器决定。

1. 点左上角 **「1 · 串口连接」** 里的 **「连接串口」** 按钮
2. 浏览器弹出**串口列表对话框**，里面列出你插的 USB-TTL
   （名字类似 `USB-SERIAL CH340`、`Silicon Labs CP210x`、`FT232R USB UART`）
3. 在对话框里**选中那个设备**，点它的「连接 / Connect」

连上后，你会看到：

- 右上角小标签从灰色「未连接」变成**绿色「已连接」**
- 面板里多出一行**「已连设备」**，显示芯片型号和 VID/PID，用来确认连对了没有
- 底部日志区多一行 `已连接串口 · 沁恒 CH340 / CH341　VID 0x1A86　PID 0x7523 · 31250 baud · 8N1`

**面板顶部那块蓝色提示是自助的**，会跟着环境变。看到红色就照着它说的做：

| 界面提示 | 含义 | 怎么修 |
|---|---|---|
| 红：*你是直接双击 `index.html` 打开的（`file://`）…* | 最常见的坑 | 改用 **`start.cmd`** 启动（见第 2 步） |
| 红：*当前页面不是安全上下文…* | 地址不是 localhost | 地址栏必须是 `http://127.0.0.1:端口/` |
| 红：*这个浏览器没有 Web Serial API* | 用了 Firefox / Safari | 换 **Chrome** 或 **Edge** |
| 蓝：*点下面的「连接串口」，然后：① ② ③* | 一切正常，等你操作 | 照它写的点 |
| 绿：*✅ 已连接* | 可以发消息了 | — |

> 「连接串口」按钮如果是**灰的、点不动**，说明上面的环境检查没过。
> 鼠标停上去会显示具体原因，面板顶部的红字也写了。

> 你在对话框里**按了取消**也没关系，日志会写「已取消：你没有选中任何设备」，重来一次即可。

### 第 4 步：发消息

- **换音色**：面板 3 直接点那 8 个按钮里任意一个（`0 · 钢琴` … `7 · 拨弦`），点一下就发出去；
  也可以手改 Bank MSB / Bank LSB / Program → 点 **「发送音色」**
- **出音**：改「音符号」（比如 60 = C4）和「力度」→ 点 **「Note On」**（面板 6）
  - 音符号和频率 Hz 是联动的，改哪个都行
- **松开**：点「Note Off」，或在面板 7「正在发声」列表里点「关」
- **同时按多个音**：勾上「保持（和弦）」，连点几次 Note On 就会叠起来；
  或者直接用面板 6 的 **和弦齐发 4 / 8 / 16 / 32**
- **调音色/音量**：面板 4 拖弯音和 CC 滑杆（CC11 = 乐器口上的音量），面板 5 是只对混音口生效的那几个

每发一条，下面的**日志区**都会记一行：时间戳 + 十六进制字节 + 人话解释。
**十六进制那一栏就是真正发到线上的字节**，怀疑哪里不对时看它最准。

> 面板 10–12 和 14（指令检查 / 一键演示 / ADSR / 杂项）默认是收起的，点标题栏才展开 ——
> 免得一屏全是控件。

### 第 5 步：收工

关掉黑窗口，或在里面按 `Ctrl+C`。

## 二、命令行方式（不想双击时）

原理和双击 `start.cmd` 完全一样，只是手动跑 `serve.ps1`。

**Windows（PowerShell）** —— 先 `cd` 到这个 `test_web` 目录：

```powershell
cd <工作区>\test_web
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

在别的目录也可以，用绝对路径即可：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\path\to\test_web\serve.ps1"
```

**Linux / macOS：**

```sh
sh serve.sh
```

**可选参数：**

| | Windows | Linux / macOS |
|---|---|---|
| 指定端口 | `-Port 8123` | `PORT=8123` |
| 不开浏览器 | `-NoBrowser` | `NO_BROWSER=1` |

默认端口按 `8000 → 8080 → 8123 → 8888 → 9000 → 9411` 顺序挑第一个空闲的。

> 服务只监听 `127.0.0.1`，**局域网里别的机器访问不到**，不用担心暴露。

## 三、接线细节

| | |
|---|---|
| FPGA 侧 | 一个 3.3V TTL 的 UART **RX**，31250 baud、8 位数据、无校验、1 位停止 |
| PC 侧 | USB-TTL（CH340 / CP2102 / FT232 等），**TX → FPGA RX**，共地 |
| 电平 | FPGA 是 3.3V；USB-TTL 务必切到 **3.3V**，5V 直连会打坏 IO |
| 位定时 | FPGA 侧 `f_clk ÷ 1573 = 31250 Hz`（误差 0.0086%），**波特率必须正好 31250** |

> ⚠ **MIDI 输入引脚（已定）**：乐器口 **C21** = PMOD2_IO0，混音口 **A17** = PMOD2_IO3。
> 两路各有一个 `midi_parse` 实例（`PORT_ID` 0~2 为乐器、3 为混音），经 `midi_arb` 仲裁后进 `midi_filter`。
> **PMOD0 (J22) 多为 SSPI/配置专用脚**（N17=`SI`、L24=`CS`、R16=`SCLK`），不能当普通 IO。

> **线插哪个口决定了哪些 CC 生效**：CC7 / 10 / 91 / 93 / 94 只在**混音口**（A17 / port3）生效，
> 插在乐器口（C21）上会被 `midi_filter.v` 丢掉。所以页面「2 · 端口与通道」的单选框要跟你实际插的口一致，
> 面板 5 顶部会按这个选择给出红字提示。

> 如果走**标准 MIDI DIN 口**（电流环），FPGA 侧还需要标准的**光耦输入电路**
> （6N138 / PC900 之类 + 220Ω 限流），USB-TTL 不能直接接 DIN 座的电流环。
> 当前阶段建议先用 TTL 直连排除软件问题。

## 四、界面（14 个面板，分 4 类）

顶部有一条**不滚动的类型栏**：`全部 / 连接 / 演奏 / 调制 / 指令 / 测试`。
点一个只显示该类面板，**日志区不受影响**（它固定在底部，不参与分类）。默认停在「全部」。

| 类型 | 面板 | 什么时候用 |
|---|---|---|
| **连接** | 1 串口连接 · 2 端口与通道 · 13 预设 | 把环境和配置弄对，一般动一次就不用再碰 |
| **演奏** | 3 音色 · 6 音符 · 7 正在发声 · 8 音符序列 | 让它出声、看它在响什么 |
| **调制** | 4 表情与滤波 · 5 混音与效果器 · 12 ADSR | 改音色 / 音质，ADSR 图还跟着 CC73/72 变 |
| **指令** | 9 手动十六进制 · 10 指令检查 · 11 一键演示 · 14 杂项 | 发单条指令、验证它对不对、跑一遍固定流程 |


面板区用**两列流**（`column-count`），列高自动平衡，不会像 grid 那样被同排最高的面板撑出空白。

| 面板 | 能做什么 |
|---|---|
| **1 串口连接** | 连接 / 断开 / **串口自检** / **更换设备**；波特率默认 31250（改成别的会亮红字警告） |
| **2 端口与通道** | 乐器端口 / 混音器端口 切换；**全局 MIDI 通道 1–16**（全页只有这一个通道） |
| **3 音色选择** | Bank MSB(CC0) + Bank LSB(CC32) + Program；**8 个音色按钮点一下直接切**，当前音色高亮 |
| **4 表情与滤波** | **弯音滑杆**（0–16383，中心 8192，显示 ±半音）+ 回中；CC1 / 11 / 74 / 71 / 73 / 72 六条滑杆；**延音踏板（CC64）开关** |
| **5 混音与效果器** | CC7 / 10 / 91 / 93 / 94 五条滑杆（**声像带「居中」按钮**）+ **效果全关 / 全开**；**在乐器口上整组禁用 + 黄字警告**（这些 CC 会被 FPGA 丢弃），切到混音口自动恢复 |
| **6 音符** | 音符号 ↔ 频率双向换算、力度滑杆、Note On/Off、保持；**和弦齐发 4 / 8 / 16 / 32 音** |
| **7 正在发声** | 保持中的音列表，可逐个 Note Off / 全部 Note Off（32 音时会滚动） |
| **8 音符序列** | 一串音符依次播放，每个音可单独指定时长和力度；**4 个一键填入**（音阶 / 半音阶 / 低→高扫 / 琶音）；播放时「正在发声」和进度都会跟着动，见下 |
| **9 手动十六进制** | 逃生舱：直接发任意字节，也便于复制到别的串口工具 |
| **10 指令检查** | 🔻 发送前按固件实际能力校验（只提示不拦）+ **30 条内置自检用例** + 本次会话 err/warn 计数 |
| **11 一键演示** | 🔻 顺序：清场 → 32 复音压测 → 8 音色轮听 → CC11 音量扫描 → CC74/CC71 滤波扫描 → 效果器全关/全开对照 → 收尾 |
| **12 ADSR 包络** | 🔻 按 RTL 参数算出的 A/D/S/R 曲线，跟着音色槽和 CC73/CC72 实时变 |
| **13 预设** | 保存到浏览器 / 恢复 / 导出 `.json` / 导入；**载入只改界面，不发字节** |
| **14 杂项** | 🔻 CC120 立即断音 / CC123 温和关音；两种 SysEx（效果参数、主音量**带拖动条**），带字节预览 |
| **发送日志** | 每行一条消息：时间戳 + 十六进制 + 人话解析。**固定在窗口底部**，上方细条可拖动改高度（双击恢复默认），高度记在浏览器里 |

> **每个面板都能点标题栏收起 / 展开**（只有「发送日志」区不折叠 —— 它得一直能看）。
> 标题右边的 `▾` = 已展开、`▸` = 已收起。🔻 标的是**默认收起**的那 5 个（10–13、15），
> 免得一进来就一屏全是控件。
> 折叠状态**不持久化**：刷新后回到默认（10–13、15 收起，其余展开），避免"上次收起了这次找不着"。

> **通道是全局的一个。** 早先「音色」和「音符」面板各有一个独立的通道输入框，
> 改一个不影响另一个 —— 名字都叫「通道」，很容易搞成「音色发到 ch1、音符发到 ch3」，
> 表现为「换了音色没效果」。现已合并为面板 2 里的**唯一一个**通道选择。

> **选过一次设备后不会再弹列表。** 「连接串口」会直接复用上次选中的端口（自检选过的也算），
> 想换设备点「更换设备」。

### 面板 8 · 音符序列怎么用

在文本框里写一串音符，点「播放」就会按顺序发 Note On / Note Off。

| 写法 | 含义 |
|---|---|
| `C4` | 音名（科学音高记号，C4 = 中央 C = 音符号 60） |
| `F#3` / `Bb5` | 升号 / 降号 |
| `60` | 直接写音符号 0–127 |
| `C4:600` | **这一个音**的发音时长 600 ms（不写就用「默认发音时长」） |
| `C4@30` | **这一个音**的力度 0–127（不写就用面板 6 的力度） |
| `C4:600@30` | 两个都写 |
| `-` | 休止符（也可写 `-:200`） |
| 空格 / 逗号 / 换行 | 分隔各项 |

「默认发音时长」对没写 `:时长` 的音生效；「音间间隔」是每个音结束到下个音开始之间的静默时间。

```
C4 D4 E4:600 60:150 -:200 G4
```

**「力度扫描」按钮**：一键填入 `C4@20 C4@50 C4@80 C4@110 C4@127` 并播放 ——
用同一个音试五个力度，**判断 FPGA 到底有没有把力度用起来**（见下）。

**4 个一键填入**（只填内容，**不会自动播放**，填错了还能改）：

| 按钮 | 填入 | 用途 |
|---|---|---|
| 音阶 | `C4 D4 E4 F4 G4 A4 B4 C5` | 听音高准不准、有没有跳音 |
| 半音阶 | `C4 C#4 … B4 C5`（12 个半音） | 最容易听出音准偏差 |
| 低→高扫 | `36 48 60 72 84 96` | 上板手册 §2 的音高范围测试 |
| 琶音 | `C4 E4 G4 C5 G4 E4` | 来回弹，听音程和包络 |

**播放时「正在发声」会跟着亮**，面板里还显示 `正在播 3/8 · E4` ——
以前序列用的是自己的内部变量，播放时面板 7 一直是「（无）」，看着像没在响。

**几个已经替你处理好的细节**

- **全角标点能认**：中文输入法下随手打出的 `：`、`，`、`、`、`；`、全角空格都会自动归一化。
- **音名大小写都行**：`c4` = `C4`。
- **认不出的项只跳过它自己**，不会让整串作废；面板下方会列出被跳过的项。
- 播放前会自动松开手动按住的音；点「全部 Note Off」也会顺带停止序列。
- **停止或播完时一定会补发 Note Off**，不会在 FPGA 上留一个一直响的音。
- 勾「循环」可反复播放（适合一边响一边调参数）。
- 面板下方实时显示「共 N 项 / M 个音 / 总时长约 X 秒」，播放前就能看到。

### 8 个音色槽

| Program | 名字 | 说明 |
|---|---|---|
| 0 | 钢琴 | 真实采样 |
| 1 | 吉他 | 真实采样 |
| 2 | 管风琴 | 真实采样 |
| 3 | 长笛 | 真实采样 |
| 4 | 槽 4 | 旧合成波形 |
| 5 | 槽 5 | 旧合成波形 |
| 6 | 锯齿强谐振 | 旧合成波形，`q_coeff = 4000` 强谐振 |
| 7 | 拨弦 | 旧合成波形，`sustain = 0`（打击感） |

名字取自 `develop/scratch/上板测试指令手册.md` §3（上板实测口径）。
**注意**：`full_system.v` 里 `tp_of()` 的注释写着「正弦 / 锯齿 / 三角」，那是**换采样之前**的描述，
只对 ADSR / 滤波器参数有效，不能当音色名用。

面板 3 里那 8 个按钮**点一下就发** `CC0 → CC32 → Program`，当前音色会高亮。
手填 Program 也会跟着高亮；填 ≥8 时全灭并提示会回绕。

### 弯音 / CC / 效果器（面板 4、5）

- **弯音**：`E0 lo hi`，14 位、中心 8192。范围 **±2 半音**，由 `chan_table.v` 的 `bend_range` 决定，
  可用 `RPN 0,0`（`CC101=0`、`CC100=0`、`CC6=<半音数>`）改。弯音**不受端口过滤影响**。
- **CC 面板里的 11 个号**都是 `midi_filter.v` 的 `cc2field()` 里真的会处理的：
  `1 / 11 / 74 / 71 / 73 / 72`（乐器口可用）+ `7 / 10 / 91 / 93 / 94`（仅混音口）。
- **拖动 40 ms 节流**：拖一次滑杆不会发几百条，松手时补发最终值。
- **效果全关/全开**：`CC91/93/94` 三个值一次发完（9 字节）。判断"炸"是不是效果器造成的，
  先把三个都设 0 再弹音 —— 但注意**上电测试模式本身就把三路效果返回强制置零**，
  所以"测试模式干净"不能作为排除效果器的依据。

### 指令检查（面板 10）

每次发送前都会按**固件实际能力**核一遍，**只提示、不拦截**（写了什么就发什么）。
判据全部取自 RTL，不看文档转述：

| 检查 | 结论 |
|---|---|
| 乐器口发 CC7/10/91/93/94 | **err**：`midi_filter.v` 会丢弃 |
| CC 号不在支持表里（如 CC2、CC121、CC124） | warn：落到 `F_NONE` 被静默忽略 |
| `An` 复音触后 / `Dn` 通道触后 | warn：落到 `default` 分支，没有作用 |
| 单独发 Program Change（缺 CC0/CC32） | warn：音色未必按预期落地 |
| 消息缺数据字节 / 孤儿数据字节 | **err**：会被丢弃 |
| SysEx 数据 > 7 字节 | **err**：`midi_filter.v` 的 `sysex_len[2:0]` 会回绕、误解析 |
| 波特率 ≠ 31250 | **err**：位定时固定 `f_clk ÷ 1573` |
| 复音 > 32 / 同音重复按下 | warn：会触发抢断 |

面板里还有 **30 条内置自检用例**（13 正例 / 17 反例），页面一打开就跑一遍，
和 `test_logic.js` 用的是同一张表 —— 两边判定不会分叉。

> **没连串口也能用**：校验在"有没有 writer"之前就跑，所以可以先把要发的东西验一遍再去接板子。

### 一键演示（面板 11）

`清场 → 32 复音压测 → 8 音色轮听 → CC11 音量扫描 → CC74/CC71 滤波扫描 → 效果器全关/全开对照 → 收尾`，
约 20 秒，随时可停（停止时补一条 `CC123`，不会在板子上留一个一直响的音）。

> ⚠ **「32 谱峰」这一段网页做不了。** 那 32 个对数振荡器是**上电测试模式**自己产生的，
> 发任何 Note On 就会退出它，而网页**无法重新进入**测试模式 —— 要听那段请给板子重新上电。
> 演示第 2 段用「32 音齐发（36→67）」代替，听感上是 32 个音同时响，但波形不是那 32 个振荡器，
> **别拿它当 32 谱峰的实测数据**。

### ADSR 包络（面板 12）

**一行数字，没有曲线图**：

`
槽 3 · A 341 ms · D 183 ms · S 61% · R 500 ms
`

- 参数取自 `full_system.v` 的 `tp_of()`（8 槽 × `a/d/s/r`）
- 时间常数按 `adsr_vca.v` 的公式反解：`attack_ms = 32768×1000 / (step×48000)`
- 已叠加面板 4 里 CC73 / CC72 的影响：`step = clamp(基准 − ((CC−64)>>>1), 1, 32767)`

> 这是**按 RTL 参数推算的**，不是从板子读回来的（单向发送，没有回读通道）。
> 它的用处是：听感上"起音好像没变"时，对着数字判断"参数上应该变多少"，
> 从而区分「没发出去」还是「发了但固件没生效」。

### 预设（面板 14）

存的是：波特率、端口模式、全局通道、Bank/Program、音符号、力度、保持、弯音、
**11 个 CC 滑杆**、序列文本与时长、手动十六进制。

- **不存串口连接状态** —— 换机器/换设备要重新在浏览器里授权一次端口
- **载入只改界面，不发送任何字节**，可以放心先载入再逐条发
- 导入时先校验 `_app` 标记和结构，所有数值走夹取，坏文件不会把界面写成一堆 `undefined`

### 杂项：CC120 与两种 SysEx（面板 15）

- **CC120 = All Sound Off**：立即硬切，正在响的音瞬间断掉，可能听到 click。
  `voice_alloc` 的 `cc_action = 1` 直接断。
- **CC123 = All Notes Off**：走 ADSR 的 RELEASE（`cc_action = 2`），更自然。
- 两者都不在端口过滤名单里，乐器口也生效。

**两种 SysEx**（参数变了会实时显示将要发送的十六进制字节）：

```
效果参数：F0 7D <组 0–3> <参数 0–15> <hi> <lo> F7      ← hi 在前（7 字节）
主音量  ：F0 7F <设备ID> 04 01 <ll> <mm> F7            ← lo 在前（8 字节）
```


> 还有几条固件支持、但页面**没有专门按钮**的指令：`CC64 / CC66`（延音 / 持有踏板）、
> `CC100 + CC101 + CC6`（RPN 0,0 改弯音范围）。这些用面板 9「手动十六进制」发，
> 校验器认不认、会不会被丢弃，面板 10 会告诉你。

### 「串口自检」是干什么的

点「连接串口」如果打不开，日志里会写 `原始异常：NetworkError · ...`。
`NetworkError` 只表示「操作系统拒绝打开这个口」，**它不告诉你为什么** —— 可能是被占用、
可能是选错了虚拟串口、也可能是驱动不接受 31250。光看这一个错名没法区分。

**「串口自检」按钮会把 31250 / 115200 / 9600 依次开了立刻关，然后给结论：**

| 自检结果 | 结论 |
|---|---|
| 31250 能开 | 串口本身没问题，直接点「连接串口」 |
| 只有 31250 开不了，别的能开 | **驱动不接受 31250 这个非标准波特率** → 必须换转换器 |
| 所有波特率都开不了 | 与波特率无关：被占用 / 选了虚拟串口 / 驱动异常 / 设备坏 |

### 端口模式为什么有区别

`硬件实现.md` §三.二.1 定死：**乐器端口会主动丢弃混音类 CC（7 / 10 / 91 / 93 / 94）**，
混音调节只认混音器端口。

- 选 **乐器端口** 时页面会警告这一点。
- **Bank Select 用的是 CC0 / CC32，不在丢弃列表内** —— 所以选音色功能在两个口上都正常。

### 选音色的三条消息必须连发

按 MIDI 规范，`CC0 → CC32 → Program Change` 必须**按此顺序连续发送**，
中间**不能插入**其他消息（尤其别的 Program Change），否则音色会选错。

点「发送音色」，或者直接点面板 3 的 8 个音色按钮，页面都是一次性发出这 8 个字节，保证顺序：

```
B0 00 <bankMsb>   B0 20 <bankLsb>   C0 <program>
```

本期音色映射是**恒等映射**：`timbre_slot = program & 7`（`技术文档.md` §四.3）。

> **注意「新音起效」**：MIDI/GM2 规定收到 Program Change 时**正在响的音不受影响**，
> 新音色只对之后按下的音符生效（`MIDI协议.md` §五）。所以换音色后要**重新按一次**才能听出来。

### 力度（velocity）

`velocity` 就是「音调强度」。但**这条链上有两个容易踩的点**，都表现为「拖滑杆音量不变」：

**① MIDI 语义：力度只在 Note On 那一刻生效。**
正在响的音不会因为拖滑杆而变响 —— 这是规范行为，不是 bug。
本页为此做了补偿：**松开滑杆（`change` 事件）时，会把还按着的音用新力度重新触发一遍**，
所以拖完就能立刻听到差别。想验证也可以直接再按一次 Note On。

**② FPGA 侧：力度曲线已经实现，但**上板还没系统验过**。**
`velocity_gain` 是**声部表的分配类字段**，由 `voice_alloc` 在分配时
从 `velocity` + 音色表 `vel_sensitivity` 派生（`硬件实现.md` §三.七、§三.六.3）。
当前实现是**力矩平方曲线** `vel_gain_fn = vel×vel`
（见 `赛题完成进度表.md`「进行中」第 3 条：代码在、编译通过，
但自动化测试 `tb_vel_amp` 被历史 X 问题挡住，**还没上板比过响度**）。
单声部层的 `adsr_vca` 只是把它当输入用。

**怎么确认是网页还是 FPGA 的问题：**

1. 看底部日志里 Note On 的第三个字节。拖滑杆前后应该是 `90 3C 64` → `90 3C 1E` 这样在变。
   - **在变** → 网页和串口都没问题，问题在 FPGA 侧（往下第 2 步）
   - **不变** → 网页的问题，告诉我
2. 点面板 8 的 **「力度扫描」**：同一个音依次用 20 / 50 / 80 / 110 / 127 触发。
   - 听起来**完全一样响** → 力度链路没通，去查 `voice_alloc.vel_gain_fn`
   - 有明显强弱变化 → 力度链路是通的（平方曲线会让低力度特别轻，这是设计如此），回到第 1 步看语义

> 也可以用面板 9「手动十六进制」直接发 `90 3C 64` 与 `90 3C 0A` 做对照，
> 完全绕开网页逻辑来判断 FPGA。

## 五、连不上 / 没反应 怎么办

**浏览器显示「拒绝连接」/ `ERR_CONNECTION_REFUSED`**
→ 意思是**本地服务没在跑**，浏览器打不到那个地址。按顺序查：

1. **黑窗口是不是被关掉了？** 关掉黑窗口就等于停服务。重新双击 `start.cmd`。
2. **黑窗口里有没有 `FAIL:`？** 有的话是 Python 没起来（没装、端口被占、参数错），
   脚本会把 Python 的原始报错都打出来，照着修；改完重新双击 `start.cmd`。
3. **地址对不对？** 用黑窗口里 `用 Chrome / Edge 打开：` 后面那个地址。
   端口是自动挑的，可能是 8080 / 8123 而不是 8000，手敲容易敲错。

> 顺带一提：`file://` 打开 `index.html` **不会**报「拒绝连接」，而是页面顶部出一段红字提示。
> 所以看到「拒绝连接」基本可以确定是服务没起来，而不是打开方式的问题。

**「连接串口」按钮是灰的 / 点不动**
→ 面板顶部的**红字**写了原因，照它做。三种可能：双击了 `index.html`（改用 `start.cmd`）、
地址不是 `127.0.0.1`、或者浏览器不是 Chromium 内核。

**点了「连接串口」，但什么也没弹出来**
→ 弹出的对话框是**浏览器的**，有时候会被浏览器窗口挡在后面，或者被弹窗拦截。
先看浏览器有没有提示"已拦截弹窗"，再重试点一次。

**串口选择框里是空的**
→ ① USB-TTL 没插好；② 驱动没装（设备管理器里看有没有带感叹号的设备）；
③ **被别的软件占用了** —— 串口助手、Arduino IDE、PuTTY 打开着同一个口时，
浏览器这边是看不到的，先全部关掉。

**日志里出现 `打不开这个串口` / `原始异常：NetworkError`**
→ 点 **「串口自检」**。它会把 31250 / 115200 / 9600 依次试一遍，直接给结论，
不用猜。三种可能：

| 自检结果 | 真正的原因 |
|---|---|
| 别的波特率能开、只有 31250 不行 | 驱动不接受 31250 这个非标准波特率 → 换转换器（FT232 / CH340 一般可以） |
| 全都开不了 | 端口被占用 / 选成了虚拟串口（如"蓝牙链接上的标准串行"）/ 驱动异常 / 设备坏 |
| 31250 也能开 | 那是一次性的偶发问题，重试即可 |

> **31250 不能改。** FPGA 侧位定时是写死的 `f_clk ÷ 1573`，换成别的波特率它收不到。
> 所以「换个波特率能连上」只是诊断手段，不能当成解决方案。

**能连上、日志也有字节，但 FPGA 完全没反应**
按这个顺序查：

1. **MIDI 线没插 / 插错口 / 接触不良** ← 现在最常见的原因
2. 波特率不是 31250（页面会警告）
3. **TX/RX 接反了** —— USB-TTL 的 TX 要接 FPGA 的**收**脚，不是发脚
4. **没共地**
5. USB-TTL 电平跳在 5V（FPGA 是 3.3V）
6. **某些 USB-TTL 驱动不支持 31250**（非标准波特率）。
   ⚠ 它**不是**"静默取整到附近值"，而是**直接在打开串口时就报错**（Web Serial 抛 `NetworkError`），
   所以这种情况你其实**连不上**，不会出现"连上了但没反应"。
   确认方法：点「串口自检」—— 只有 31250 开不了、别的能开，就是它。
   解决办法是换转换器（FT232 / CH340 一般可以，CP2102 与部分 PL2303 看驱动版本）
7. 引脚 `.cst` 约束错了或没约束

**日志里字节是对的，但听不到声音**
→ 检查 PA_EN 是否拉高、耳机插在 J29、功放使能（`硬件实现.md` §二.2）

## 七、已知限制 / 后续可加

- **单向发送**：FPGA 侧 4 路 UART **全是接收**，没有回传通道，
  所以调试器看不到设备状态（声部分配、`env_state`、实际音量）。
  面板 13 的包络图是按 RTL 参数**算**的，不是读回来的。
  若以后加一个 debug UART TX，这个页面加一个接收区就能显示/画图。
- **网页进不了测试模式**：上电那 32 个对数振荡器是硬件自己起的，网页只能发 Note On 把它**退出**，
  没法让它回去 —— 要再听只能重新上电。
- **序列没有导出/导入**（但可以用面板 14 的预设把序列文本一起存下来）。
- **没有录制/回放**，没有导出 `.mid`。
- **字节间隔没有做成可调**：普通通道消息在 31250 baud 下本来就按波特率发送（一字节 320 µs），
  固件侧**没有**字节间超时；只有 SysEx 有 10 ms 字节间超时，而本页发的 SysEx 都是几字节一条，
  不会触发。真要人为加间隔反而会让 "延迟 ≤10 ms" 那条演示项变差。

### 找不到 Python 怎么办（已修）

`serve.ps1` 按这个顺序找解释器，**每个候选都会真的跑一遍** `<python.exe> -c "import sys"`，
跑得通才算数（光看文件存在不够 —— 机器上就可能留着一个只剩 `Lib\` 的空壳目录）：

1. **PATH 上的** `python3` / `python` / `py`
2. **常见安装位置**：`D:\anaconda\python.exe`、`D:\anaconda3\python.exe`、
   `%USERPROFILE%\anaconda3\`、`%USERPROFILE%\miniconda3\`、
   `%LOCALAPPDATA%\Programs\Python\Python3*\`、`%ProgramFiles%\Python3*\`、
   以及 `ANACONDA_HOME` / `CONDA_PREFIX` 环境变量指向的位置

Windows 上 `python` / `python3` 很可能是 **Microsoft Store 的占位符**（跑一下返回
`-1073740791`，点开会弹应用商店），`py` 也可能因为没有注册解释器而返回 `112` ——
所以第 2 步的兜底是必需的。

仍然找不到时，启动脚本会把**试过哪些路径**全列出来，然后退出。两个办法：

- 装一个真的 Python 3（只用标准库，不用装任何包），装完重开一个窗口；
- 或者直接指定解释器：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Python D:\anaconda\python.exe
```

> ⚠ **`serve.ps1` 必须保存为 UTF-8 带 BOM。** Windows PowerShell 5.1（`start.cmd` 用的就是它）
> 靠 BOM 判断编码；没有 BOM 时会把中文注释按 GBK 解码，报的错是
> `Missing ')' in function parameter list` 这种完全对不上号的语法错误。

> `start.cmd` 只能是**纯 ASCII + CRLF**（cmd.exe 的要求），改它时别加中文。
