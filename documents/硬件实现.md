## 二、时钟

### 2.1 时钟源现状

| 源 | 频率 | 引脚 | 说明 |
|---|---|---|---|
| 板载有源晶振（SOM） | **50 MHz** | **V22** | 直接可用，进 RPLL0/RPLL1 |
| MS5351 #1 / #2（Dock） | 可编程 | **`USR_CLK_IN`（引脚待确认）** | 可精确合成音频时钟 |
| 片内 OSC | 210/Param MHz | — | 精度差，不可用于音频 |

### 2.2 f_clk 选型【已定：49.152 MHz】

**约束**

- I2S 帧 = 每声道 16 bit（PT8211 限制）→ 若 BCLK 用 16 bit/声道，一帧 32 个 BCLK
- 若要 `MCLK = 256 × f_s = 12.288 MHz`，需 `f_clk / MCLK` 为整数
- 采用「单一主时钟 + clock enable」架构，避免跨时钟域

**为什么不能用 50 MHz 直接得到 48 kHz**

```
f_clk / f_s = 48000 × 2ⁿ / 50,000,000 = 2ⁿ × 3 / 5⁵
                                                    ↑ 分母恒含 5⁵
```

（`50,000,000 = 2⁷ × 5⁸`，`48000 = 2⁷ × 3 × 5³`）

VCO 上限 2 GHz（官方 DS1104 Table 3-18），约去 5⁵ 需大分频比 → VCO 被顶到约 6144 MHz ✗。
**⇒ 49.152 / 98.304 MHz 无法从 50 MHz 得到**（内部分频器只能提供 2 的幂，提供不了所需的 5）。
这一结论已用官方参数核实：`UG306` Table 5-3/5-13 —— `IDIV 1~64`、`FBDIV 1~64`、`ODIV 1~128`、小数分频仅 1/8 与 0~7。

**⇒ 采用方案：由 MS5351 提供 12.288 MHz，FPGA 内部 PLL ×4 得到 49.152 MHz**

```
MS5351（25 MHz 晶振）
    │  N = 31 + 1429/3125 = 31.45728，输出整数分频 ÷64
    ↓
12.288 MHz（= 256 × f_s）
    │  进 FPGA 时钟引脚（USR_CLK_IN → 引脚待确认）
    ↓
FPGA PLLA：IDIV=1, FBDIV=2, MDIV=64, ODIV0=32
    │  Fpfd = 12.288 MHz ✓（10~400）
    │  VCO  = 12.288 × 2 × 64 = 1572.864 MHz ✓（800~2000）
    ↓
f_clk = 1572.864 / 32 = 49.152 MHz ✓
```

**这样做的两个好处**

1. **抖动更低**：MS5351 的杂散/抖动经过 FPGA PLL 会被滤除一部分；比直接送 49.152 MHz 更干净
2. **MCLK 免费**：PLL 的出 1 通道 `ODIV1=4` 直接得到 12.288 MHz 作 MCLK

**分频结果核对**（`f_clk = 49.152 MHz`，`N_cyc = 49.152e6 / 48e3 = 1024`）

| 信号 | 频率 | 分频比 | 是否是 `2 的幂` | 占空比 |
|---|---|---|---|---|
| `f_s` / LRCK | 48 kHz | 1024 | ✓ | 50% |
| BCLK | 1.536 MHz（= 32 × f_s） | 32 | ✓ | 50%（每 16 拍翻转） |
| MCLK | 12.288 MHz（= 256 × f_s） | 4 | ✓ | 50% |
| MIDI 位时钟 | 31250 Hz | 1572.864 ✗ → **1573** | — | 误差 **0.0086%** |
| I2C SCL | 400 kHz | 122.88 ✗ → 123（399.6 kHz）或 128（**384 kHz**） | — | — |

> `N_cyc` 是 2 的幂，**所有 I2S 相关分频都是整数且占空比 50%** —— 这是选 49.152 MHz 的最大好处。
> MIDI / I2C 的微小误差远小于各自容差（UART ±2%，I2C 无严格下限）。

**⚠️ 本方案依赖一项硬件事实（待确认）**

`USR_CLK_IN` 究竟接到哪个 FPGA 引脚？文字提取指向 BTB 的 **75 / 76 脚（→ N22 / N23）**，
**但需看图或用 KiCad 源确认**，并确认该引脚能否驱动 PLL。

### 2.3 时钟树

```
MS5351（25 MHz）×1
    │
    ↓ 12.288 MHz ──→ USR_CLK_IN ──→ FPGA 时钟引脚
    │
PLLA：IDIV=1 / FBDIV=2 / MDIV=64
    ├── CLKOUT0 → ODIV0=32 → 49.152 MHz ──→ BUFG ──→ f_clk（全逻辑）
    └── CLKOUT1 → ODIV1=4  → 12.288 MHz ──→ ODDR ──→ MCLK 给 DAC（若需要）
    │
f_clk = 49.152 MHz（单一主时钟域）
    │
    ├── sample_enable   ÷1024  → 48 kHz，周期类节拍
    ├── bclk_enable     ÷32    → 1.536 MHz，I2S 移位（每 16 拍翻转）
    ├── lrck_enable     ÷1024  → 48 kHz，I2S 声道切换
    ├── midi_tick       ÷1573  → 31250 Hz（误差 0.0086%）
    └── i2c_tick        ÷128   → 384 kHz
    │
    └── 输出时钟生成（ODDR）
         ├── BCLK   1.536 MHz  → DAC（PT8211）
         ├── LRCK   48 kHz     → DAC
         └── MCLK   —          → 本项目 PT8211 不需要 MCLK
```

> **备用**：若 `USR_CLK_IN` 走线不可用，退路是 `f_clk = 50 MHz` 直连，采样率变为 **48.828 kHz**（音高约 +30 音分），
> 此时 N = 1024、BCLK = 1.526 MHz、MIDI 精确整除（÷1600）。属可用折中。

### 2.4 clock enable 与真实时钟

**内部逻辑：全部使用 clock enable，仅有一个时钟域。**

- 所有寄存器都挂在 `f_clk` 上，用 `sample_enable` / `bclk_enable` 等使能控制节拍
- 好处：**内部无跨时钟域问题**，不需要同步器 / 异步 FIFO
- 代价：使能信号需要扇出到全芯片，需注意扇出平衡

**对外输出：必须用真实时钟。**

- BCLK / LRCK 要送到 DAC，须用 **ODDR** 生成（保证占空比与相位关系）
- 不要用「普通寄存器输出」当时次用

**仍需处理的三处时钟域边界：**

| 边界 | 处理 |
|---|---|
| MIDI 输入（外部异步串行） | 两级触发器同步，必要时加去毛刺 |
| I2S 输出时钟（ODDR 输出） | 与主逻辑同源，无需 FIFO |
| 复位（异步输入） | 同步释放（见 §三） |

### 2.5 外部时钟源 MS5351（待确认）

板上 2 颗 `MS5351M` 是 Si5351 的国产替代，**分数分频的分母是可配置的 20 位整数（最大 1048575）**，
因此能精确合成音频标准时钟（与 FPGA 内部 PLL 只能提供 2 的幂不同）。

**合成 12.288 MHz 的参数（从 25 MHz 晶振，误差 0 ppm）**

```
VCO  = 12.288 × 64 = 786.432 MHz     ✓（MS5351 VCO 范围约 600~900 MHz）
N    = 786.432 / 25 = 31.45728 = 31 + 1429/3125
       → a = 31（需 15~90）✓，b = 1429，c = 3125（需 ≤ 1048575）✓
输出分频 = 64（整数、偶数 → 占空比 50%）
结果 = 25 × (31 + 1429/3125) / 64 = 12.288 MHz   ✓ 误差 0
```

（也可让它直接输出 49.152 MHz：同一 VCO 786.432，输出分频改 ÷16）

**使用注意**

- **扩频（Spread Spectrum）必须关闭**，否则会毁掉音频时钟
- 用「PLL 分数 + 输出整数分频」的配置，抖动比「输出也分数」好
- MS5351 输出为 3.3 V CMOS 方波；需确认与 FPGA 时钟引脚的电平兼容

**⚠️ 待确认（需查图 / KiCad 源）**

1. **`USR_CLK_IN` 接到哪个 FPGA 引脚**
2. 该引脚是否为**时钟专用引脚**（能驱动 PLL）
3. MS5351 上电默认输出什么频率（是否有 EEPROM 自动加载）
4. 两颗 MS5351 的分工（哪颗给 `USR_CLK_IN`）

> 参考：`vdalex/tangmega-138k-fpga-projects` 是同板卡的第三方项目，含 **PT8211 DAC 发射器** 与 PLL 配置，可对照。

## 三、复位

### 3.1 方案

采用 **异步复位、同步释放**：

```
rst_n (异步)  ──→ [触发器1] ──→ [触发器2] ──→ rst_sync_n
                   ↑          ↑
                 f_clk      f_clk
```

- **异步断言**：复位到来立即生效，不依赖时钟（上电、外部复位都能立刻起作用）
- **同步释放**：释放沿与 `f_clk` 对齐，避免亚稳态
- 复位信号应走**专用复位网络**（Gowin 的全局复位资源），不要用普通布线

### 3.2 复位情况表

| 模块 / 资源                        | 复位后的状态                                            | 说明                   |
| ------------------------------ | ------------------------------------------------- | -------------------- |
| **声部状态表**                      | 全部置 IDLE；`gate` = 0；运行状态字段归零                      | 不得残留上一轮的相位 / 包络      |
| **通道状态表**                      | 运行参数归零或默认；配置项（`max_voices`、`default_timbre`）载入默认值 |                      |
| **音色参数表 / 波表 / 音色映射表 / 鼓组映射表** | **不受复位影响**                                        | BRAM 初值已固化；复位不清 BRAM |
| **效果参数表**                      | 载入默认值                                             | 由上位机 / 混音器后续修改       |
| **主输出参数表**                     | 载入默认值                                             | 同上                   |
| **效果器延迟线**                     | 清零                                                | 避免残留旧数据产生噪声          |
| **MIDI 消息解析**                  | 状态机回 IDLE；运行状态缓存清零                                | 复位后必须等待新的状态字节        |
| **声部时序器**                      | 计数器归零                                             | 与采样边界重新对齐            |
| **声部取数器**                      | 预取寄存器置无效                                          |                      |
| **声部分配 / 释放器**                 | 无待处理事件                                            |                      |
| **I2S 发送**                     | 停止移位输出                                            |                      |
| **全局 `ready`**                 | 复位释放后置低，**各表载入完成后置高**                             | 门控 I2S 输出，避免载入期间发声   |

**关键点：**

- **BRAM 初值不受复位影响** —— 只读表（音色 / 波表 / 映射表）无需复位逻辑，靠综合时写入的初值
- **延迟线必须清零** —— 否则上电会有残留噪声
- **`ready` 门控** —— 保证「表载入完成前不发声」（对应技术文档的启动时序要求）

### 4.3 数据格式【关键：PT8211 不是标准 I2S】

**PT8211 使用 LSBJ（Least Significant Bit Justified）格式，又称「日本格式」。**

| 特性 | PT8211（LSBJ） | 标准 I2S |
|---|---|---|
| 位序 | **MSB 先出**，二进制补码 | MSB 先出 |
| MSB 位置 | **紧贴 WS 跳变** | 跳变后**延后 1 个 BCK** |
| WS 极性 | **WS 高 = 左声道**，低 = 右声道 | WS **低** = 左声道 |
| 位宽 | **16 bit**（多出的位被截断） | 视器件 |

**⇒ 若直接套用标准 I2S，会出现：左右声道颠倒**（WS 极性相反），且位对齐差 1 拍。

**帧结构**

```
WS:    ┌── 左声道 ──┐┌── 右声道 ──┐
       │  16 × BCK  ││  16 × BCK  │
DIN:   MSB ... LSB   MSB ... LSB
       ↑                ↑
       紧贴 WS 跳变      紧贴 WS 跳变
```

- 每声道 **16 个 BCK**，一帧共 **32 个 BCK** → `BCLK = 32 × 48 kHz = 1.536 MHz` ✓
- 数据在 **BCK 下降沿**更新，**上升沿**被 DAC 采样
- **PT8211 不需要 MCLK**（内部自有时钟）

**PT8211 电气约束（已核对）**

| 项 | 限制 | 我们 |
|---|---|---|
| BCK 频率 | ≤ 18.4（可到 20）MHz | 1.536 MHz ✓ |
| WS 频率 | ≤ 384 kHz | 48 kHz ✓ |
| 输入高电平 VIH | ≥ 1.8 V（VDD=5V 时） | FPGA 3.3 V ✓ |
| 供电 | 板载 +5V（`5V0A`） | ✓ |

| 对齐方式 | **LSBJ（日本格式）**，非标准 I2S |
| MCLK | 不需要 |

### 4.5 实现要点

**移位与对齐**
- MSB 先出，**紧贴 WS 跳变**（不是 I2S 的延后 1 拍）
- 每声道恰好移 16 位
- **WS 高 = 左声道**（与 I2S 相反，务必确认，否则左右颠倒）

**时钟沿**
- 输出用 **ODDR** 生成 BCLK / LRCK
- 数据在 BCLK **下降沿**更新，DAC 在上升沿采样

**位深匹配**
- 我们内部可保持 24 bit 精度，**送 DAC 前截断/舍入到 16 bit**（建议带抖动 dither，否则小信号失真）
- 若误按 24 bit 对齐发送，数据会整体错位 → 音量异常或噪声

**验证手段**
- 先用单频正弦（如 1 kHz）测试，示波器同时看 BCLK / LRCK / DIN
- **重点核对两个点**：① MSB 是否紧贴 WS 跳变；② WS 高电平对应左声道

> （princeton.com.tw → Multi-Media Audio → DAC → PT8211），以核对波形图。
> 另可参考同板卡项目 `vdalex/tangmega-138k-fpga-projects` 的 PT8211 发射器实现。
