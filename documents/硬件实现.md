# 硬件实现

> 板卡：Tang Mega 138K Pro（GW5AST-LV138FPG676A）
> 时钟细节有待验证，这决定了时钟采用哪种方案

## 一、时钟

### 1.1 晶振

板载 **50 MHz 有源晶振**，接入 FPGA 时钟引脚 **V22**（LVCMOS33，3.3V Bank）。

> 来源：Sipeed 例程的约束文件（`.cst` / `.sdc`，周期 20 ns）。**需以官方原理图最终确认。**

板上另有 **2 颗 MS5351** 时钟发生器，官方说明用于 SerDes 参考时钟。

### 1.2 f_clk 选型

**约束条件：**

- I2S 一帧含 **64 个 BCLK**（2 声道 × 32 位）→ 要求 `N = f_clk / f_s` 能被 **64** 整除
- 若需 `MCLK = 256 × f_s`，还要求 `N` 能被 **256** 整除（即 N 含 2⁸）
- 采用「单一主时钟 + clock enable」架构，避免跨时钟域

**关键结论：48 kHz 一族时钟无法从 50 MHz 得到**

```
f_clk / f_s = 48000 × 2ⁿ / 50,000,000

48000 × 2ⁿ      2ⁿ × 3
──────────  =  ────────      ← 分母恒含 5⁵
50,000,000       5⁵
```

（因 `50,000,000 = 2⁷ × 5⁸`，而 `48000 = 2⁷ × 3 × 5³`）

要约去 5⁵ 必须使用大分频比，VCO 会被顶到 ~6144 MHz，**远超 GW5AST 上限（约 2000 MHz）**。
⇒ **49.152 MHz / 98.304 MHz 在本板上取不到**（整数与小数分频均不可行）。

**可选方案：**

| 方案 | f_clk | 来源 | `f_s` | 误差 | MCLK | BCLK | MIDI 波特率 |
|---|---|---|---|---|---|---|---|
| **A** | 50 MHz | 晶振直连 | 48.828 kHz | +1.73% | 12.5 MHz = 256 fs ✓ | 3.125 MHz = 64 fs ✓ | **精确**（÷1600） |
| **B** | 100 MHz | PLL | 48.828 kHz | +1.73% | 12.5 MHz = 256 fs ✓ | 3.125 MHz = 64 fs ✓ | **精确**（÷3200） |
| **C** | 76.8 MHz | PLL | **48.000 kHz** | **0%** | 9.6 MHz = 200 fs（非标准） | 3.072 MHz，占空比 48/52% | 0.016%（÷2458） |
| D | 96 MHz | PLL | 46.875 kHz | −2.34% | 12 MHz = 256 fs ✓ | 3 MHz = 64 fs ✓ | **精确**（÷3072） |

**方案 A 说明**（N = 1024）
- **不需要 PLL**，直接使用 50 MHz 晶振 → **零 PLL 抖动**
- N = 1024 = 2¹⁰ → MCLK / BCLK 全为整数分频，比例标准
- MIDI 波特率 `50e6 / 31250 = 1600` **整除**，不需累加器
- 唯一代价：采样率偏高 1.73%（音高约高 30 音分）

**方案 C 说明**（N = 1600）
- 采样率**精确 48 kHz**
- PLL 参数：`IDIV = 10`、`ODIV = 25`、`FBDIV × MDIV = 192` → VCO = 1920 MHz
  （备选：`IDIV = 5`、`FBDIV × MDIV = 192`，Fpfd = 10 MHz）
- 代价：`MCLK = 256 fs` 无法整数分频（1600/256 = 6.25）→ 只能给 **200 fs**
  - **需确认 DAC 是否接受 200 fs 的 MCLK 比例**
  - 若不接受，需另配 MCLK 源（见 §1.4）

**待定**：最终取值需在 Gowin EDA 的 PLL IP 生成器中验证（含 VCO / Fpfd / 输出范围的实际约束）。

### 1.3 时钟树（以方案 A / f_clk = 50 MHz 为例）

```
板载 50 MHz 有源晶振（V22）
    │
    ↓
全局时钟缓冲（BUFG）
    │
    ↓
f_clk = 50 MHz ──→ 全 FPGA 逻辑（单一主时钟域）
    │
    ├── sample_enable      ÷1024          → 48.828 kHz，周期类节拍
    ├── bclk_enable        ÷32           → 1.5625 MHz，I2S 移位（每 16 拍翻转）
    ├── lrck_enable        ÷1024         → 48.828 kHz，I2S 声道切换
    ├── midi_tick          ÷1600         → 31250 Hz，MIDI 波特率（整数）
    └── i2c_tick           ÷125          → 400 kHz，I2C 速率
    │
    └── 输出时钟生成（ODDR）
         ├── BCLK   3.125 MHz   → DAC
         ├── LRCK   48.828 kHz  → DAC
         └── MCLK   12.5 MHz    → DAC（若需要）
```

> 若改用方案 C（f_clk = 76.8 MHz），则 `sample_enable` 为 ÷1600，`midi_tick` 为 ÷2458，
> BCLK 半周期为 12.5 拍（需用 12/13 交替），MCLK 需另行安排。

### 1.4 clock enable 与真实时钟

**内部逻辑：全部使用 clock enable，仅有一个时钟域。**

- 所有寄存器都挂在 `f_clk` 上，用 `sample_enable` / `bclk_enable` 等使能控制节拍
- 好处：**内部无跨时钟域问题**，不需要同步器 / 异步 FIFO
- 代价：使能信号需要扇出到全芯片，需注意扇出平衡

**对外输出：必须用真实时钟。**

- BCLK / LRCK / MCLK 要送到 DAC，须用 **ODDR** 生成（保证占空比与低抖动）
- 不要用「普通寄存器输出」当时钟用

**仍需处理的三处时钟域边界：**

| 边界 | 处理 |
|---|---|
| MIDI 输入（外部异步串行） | 两级触发器同步，必要时加去毛刺 |
| I2S 输出时钟（ODDR 输出） | 由同一 PLL / 晶振分频，与主逻辑同源，无需 FIFO |
| 复位（异步输入） | 同步释放（见 §二） |

### 1.5 备用时钟源（待查）

板上 **MS5351**（可编程时钟发生器）本质是小分频 PLL，**理论上能精确合成 12.288 / 24.576 MHz 等音频标准时钟**。

- 若其中一路输出可接到 FPGA 的通用时钟引脚，则 48 kHz 一族问题可彻底解决
- **需查官方原理图确认走线**，以及由谁控制（官方说明经板载 UART 控制）

## 二、复位

### 2.1 方案

采用 **异步复位、同步释放**：

```
rst_n (异步)  ──→ [触发器1] ──→ [触发器2] ──→ rst_sync_n
                   ↑          ↑
                 f_clk      f_clk
```

- **异步断言**：复位到来立即生效，不依赖时钟（上电、外部复位都能立刻起作用）
- **同步释放**：释放沿与 `f_clk` 对齐，避免亚稳态
- 复位信号应走**专用复位网络**（Gowin 的全局复位资源），不要用普通布线

### 2.2 复位情况表

| 模块 / 资源 | 复位后的状态 | 说明 |
|---|---|---|
| **声部状态表** | 全部置 IDLE；`gate` = 0；运行状态字段归零 | 不得残留上一轮的相位 / 包络 |
| **通道状态表** | 运行参数归零或默认；配置项（`max_voices`、`default_timbre`）载入默认值 | |
| **音色参数表 / 波表 / 音色映射表 / 鼓组映射表** | **不受复位影响** | BRAM 初值已固化；复位不清 BRAM |
| **效果参数表** | 载入默认值 | 由上位机 / 混音器后续修改 |
| **主输出参数表** | 载入默认值 | 同上 |
| **效果器延迟线** | 清零 | 避免残留旧数据产生噪声 |
| **MIDI 消息解析** | 状态机回 IDLE；运行状态缓存清零 | 复位后必须等待新的状态字节 |
| **声部时序器** | 计数器归零 | 与采样边界重新对齐 |
| **声部取数器** | 预取寄存器置无效 | |
| **声部分配 / 释放器** | 无待处理事件 | |
| **I2S 发送** | 停止移位输出 | |
| **全局 `ready`** | 复位释放后置低，**各表载入完成后置高** | 门控 I2S 输出，避免载入期间发声 |

**关键点：**

- **BRAM 初值不受复位影响** —— 只读表（音色 / 波表 / 映射表）无需复位逻辑，靠综合时写入的初值
- **延迟线必须清零** —— 否则上电会有残留噪声
- **`ready` 门控** —— 保证“表载入完成前不发声”（对应技术文档的启动时序要求）
