# 使用手册

## 一、简介

- 芯片：高云GW5AST-LV138FPG676A
- 开发板：Sipeed Tang Mega 138K Pro
- clk50=P16(50M) clk12288=N22(24.576M)
- 系统时钟：49.152 MHz
- 采样率： 48 kHz
- 复音： 32（8 泳道×4 时隙）
- 音色： 8槽

## 二、常用引脚
| 功能       | 引脚                                                                          | 说明                              |
| -------- | --------------------------------------------------------------------------- | ------------------------------- |
| MIDI 入 0 | C21、B20、B19                                                                 | 乐器口（音符/力度/CC1/11/71~74/弯音/PC）   |
| MIDI 入 1 | B20                                                                         | 乐器口（与 C21 同功能，第 2 个乐器口）         |
| MIDI 入 2 | B19                                                                         | 乐器口（与 C21 同功能，第 3 个乐器口）         |
| MIDI 入 3 | A17                                                                         | 混音口：**CC7/10/91/93/94 只此口生效**   |
| 音频探针     | C24                                                                         | sample_l 的 1 位 SD（需 RC 1k+10nF） |
| 声部探针     | E25                                                                         | voice_aud 八泳道求和                 |
| DDS 探针   | L17                                                                         | 泳道 0 波形                         |
| 其他探针     | **A20** 心跳 11.7 Hz（验证引脚）｜ **A19** 音符门控（**测延迟可用它**）｜ **B21** 出声（门控 + 幅度≥128） | 用于测试                            |
| LED      | M25 L20 N21 R26                                                             | LED0~LED3                       |

## 三、模式
- **测试模式**：上电自动进入，32 个对数振荡器 200 Hz~8 kHz；发任一 Note On 退出。
- 效果/主音量参数：`EXT_FXPARAM=0`（内置默认）、`MVOL_EXT=1`（主音量走 SysEx），见 full_system.v。
- 限幅器/去直流/抖动常开。
- LED用于测试音色槽状态，规则如下：

| LED      | 引脚  | 规则                                 | 含义                         |
| -------- | --- | ---------------------------------- | -------------------------- |
| **LED0** | M25 | `dbg_led[0] = ~pf_timbre[0]`       | 当前音色槽编号的 bit0              |
| **LED1** | L20 | `dbg_led[1] = ~pf_timbre[1]`       | bit1                       |
| **LED2** | N21 | `dbg_led[2] = ~pf_timbre[2]`       | bit2                       |
| **LED3** | R26 | `dbg_led[3] = ~(dbg_evt_cnt != 0)` | **起音脉冲**：任何声部被门控的**上升沿**点亮 |
