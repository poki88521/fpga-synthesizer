# 单声部合成引擎技术文档

**适用平台：高云 GW5A-138K（Sipeed Tang Mega 138K Pro）**  
**系统时钟：49.152 MHz**  
**音频采样率：48 kHz（每采样周期 1024 拍）**  
**文档版本：v2.2（2026-10-04）**

---

## 一、概述

单声部是电子乐器合成引擎的最小发声单元。每个声部独立完成：

```
波表 DDS 生成波形 → SVF 滤波塑形 → VCA 包络增益 → 输出至通道混音总线
```

所有模块在 `sample_en`（每 1024 个时钟拍产生一个脉冲）有效时更新。当前支持 **2 种音色**（钢琴、吉他），通过音色槽 `timbre_slot` 选择。后续可扩展至更多音色。

---

## 二、系统时钟与采样率

| 参数 | 值 |
|---|---|
| 系统时钟 `f_clk` | 49.152 MHz |
| 音频采样率 `f_s` | 48,000 Hz |
| 每采样周期时钟拍数 | 1024 |
| 采样使能脉冲间隔 | 1024 拍 |
| I2S 主时钟 MCLK | 12.288 MHz（= 256 × fs） |

49.152 MHz ÷ 1024 = 48,000 Hz，整除，时序干净。

## 三、复位方案：异步复位、同步释放

每个模块内部例化复位同步器，将外部异步复位 `rst_async_n` 转换为与 `clk` 同步的 `rst_n_sync`。

```verilog
module reset_sync (
    input  wire clk,
    input  wire rst_async_n,
    output wire rst_n_sync
);
    reg rst_meta, rst_sync;
    always @(posedge clk or negedge rst_async_n) begin
        if (!rst_async_n) begin
            rst_meta <= 1'b0;
            rst_sync <= 1'b0;
        end else begin
            rst_meta <= 1'b1;
            rst_sync <= rst_meta;
        end
    end
    assign rst_n_sync = rst_sync;
endmodule
```

所有时序逻辑使用 `rst_n_sync` 复位。

## 四、音色表设计

### 4.1 音色槽与波表

当前音色槽数：**2**

| `timbre_slot` | 音色 | 波表地址范围 | `wave_sel` |
|---|---|---|---|
| 0 | 钢琴 | 0 ~ 4095 | 0 |

| 字段 | 钢琴 | 吉他 |
|---|---|---|
| `wave_main` | 0 | 1 |
| `adsr_attack`（ms） | 125 | 10 |
| `adsr_decay`（ms） | 500 | 200 |
| `adsr_sustain`（整数） | 32844（约 0.5） | 16476（约 0.25） |
| `adsr_release`（ms） | 300 | 100 |
| `adsr_curve` | 1（指数） | 1（指数） |

**换算说明**：
- 时间参数单位：**毫秒**
- Sustain：`sustain_level = 65535 × 10^(-dB/20)`，钢琴衰减 6 dB → 32844，吉他衰减 12 dB → 16476
- 截止频率系数：`f = 2 × sin(π × fc / fs)`，Q1.15 格式
- 阻尼系数：`q = 1/Q`，Q1.15 格式

### 4.4 波表读取（多声部并发问题与方案）

**问题（简述）**

波表是所有声部共享的资源。但在 **P = 8 条并行泳道 × G = 4 个串行时隙** 的结构下，同一时隙内 8 条泳道同时工作，**同一时钟拍会出现 8 个不同地址要同时读出**（若做插值，每声部需读相邻两点 → 每拍 16 次读）；而单口 BSRAM 每拍只能读 1 次，无法直接支持。

若改为**为每个声部各复制一份波表 ROM**，则 32 声部要占用 **约 224~256 块 BSRAM（占全片 340 块的 66%~75%）**，再叠加主通道的效果器 + 延迟线（约 148 块）**必然超出片上总量**。因此复制方案不可行。

**方案：时隙内串行读 + 寄存器缓存**

核心思路：**全片只保留 1 份波表 ROM（8 块 BSRAM），用"时间换口数"** —— 在时隙开始处用若干拍把该时隙所需样本**依次读出并存入寄存器**，之后 8 条泳道照常并行计算。

结构：

```
         ┌────────────────────────────────────────┐
 地址 ──▶│  波表 ROM（全局 1 份，8192 × 16 bit）    │
（来自   │                                        │
 取数器）└──────────────┬─────────────────────────┘
                        │ 每拍读 1 个地址，串行
                        ▼
              [ P 个声部的样本寄存器 ]（每声部 2 个：n 与 n+1）
                        │
                        ▼
        P 条泳道并行做 线性插值 → SVF → VCA
```

时序（以 1 个时隙、P = 8 为例）：

```
拍:   0      1      2      3    ...   14     15     16...
操作: 读n0 → 读n0+1 → 读n1 → 读n1+1 → ... 读n7 → 读n7+1 → [8 条泳道并行计算]
      └──────────── 16 拍串行读（单口）────────────┘
```

- 前 16 拍：单口 ROM 依次读 8 声部 × 2 点，分别存入 16 个寄存器；
- 之后：P 条泳道用寄存器中的值**并行**完成插值及其余运算。

开销核算（`f_clk = 49.152 MHz`，`f_s = 48 kHz`，每采样 `N_cyc = 1024` 拍）：

| 项 | 拍数 |
|---|---|
| 每时隙串行读（单口，2 × P） | 16 |
| 每采样共 G 个时隙 | 16 × 4 = **64 拍（6.3%）** |
| 若 ROM 用双口（每拍读一个声部的 2 点） | 8 拍/时隙 → 每采样 32 拍（3.1%） |

现有声部处理只占 `G × L ≈ 80` 拍（7.8%），加上本项仍**余量充足**；若把读取做成**预取**（读 slot g+1 的地址时，slot g 正在计算），这几十拍可**完全隐藏在计算时间之后，额外开销 ≈ 0**。

**实现要点**

1. **同步读延迟**：BSRAM 输出比地址晚 1 拍，串行读的循环要把这 1 拍计入（地址与数据错开一拍）。
2. **插值两点先入寄存器**：`tab[n]` 与 `tab[n+1]` 都取回后，再由泳道算 `wave = tab[n] + (tab[n+1] − tab[n]) × frac / 256`。
3. **地址来源**：每个声部的 `phase_acc` 由**声部取数器**在时隙开始时取出（它本就要预取声部表 / 通道表 / 音色参数表），波表读只需取这 P 个 `phase_acc` 的高位作地址，接口干净。
4. **不能按泳道分 bank**：声部状态表可按泳道分 bank（每条泳道只读自己的行），但**波表地址是任意相位**，无法按泳道划分，只能靠时间复用。

**结论**：波表**全局 1 份、不复制**；每时隙用 8~16 拍串行读出 P 个声部所需样本（含插值两点）存入寄存器，再并行计算。代价约 3%~6% 的时间（可预取隐藏），换来**约 240 块 BSRAM**。

## 五、DDS 模块

### 5.1 功能

通过 32 位相位累加器产生数字相位，取高 12 位作为波表整数地址，低 8 位作为小数部分，使用双端口 ROM 同时读取相邻两点，进行**线性插值**，输出 24 位有符号波形样本。

### 5.2 接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | 输入 | 1 | 49.152 MHz |
| `rst_n_sync` | 输入 | 1 | 同步后复位 |
| `sample_en` | 输入 | 1 | 每 1024 拍一个脉冲 |
| `phase_inc` | 输入 | 32 | 频率控制字 |
| `wave_sel` | 输入 | 2 | 当前只用 `[0]` |
| `phase_acc` | 输出 | 32 | 写回声部状态表 |
| `wave_out` | 输出 | 24 | 有符号，送往 SVF |

### 5.3 波表插值实现

- 整数地址：`addr_n = phase_acc[31:20]`（12 位）
- 下一地址：`addr_n1 = addr_n + 1`
- 小数部分：`frac = phase_acc[19:12]`（8 位，代表 0~255/256）
- 插值公式：`wave_out = tab[n] + (tab[n+1] - tab[n]) × frac / 256`

需要双端口 ROM 同时读取 `tab[n]` 和 `tab[n+1]`。

### 5.4 关键代码

```verilog
module dds_voice (
    input  wire        clk,
    input  wire        rst_n_sync,
    input  wire        sample_en,
    input  wire [31:0] phase_inc,
    input  wire [1:0]  wave_sel,
    output reg  [31:0] phase_acc,
    output reg  signed [23:0] wave_out
);

    reg  [11:0] addr_n, addr_n1;
    reg  [7:0]  frac;
    wire signed [15:0] tab_n, tab_n1;
    wire signed [31:0] diff;
    wire signed [39:0] interp;

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync)
            phase_acc <= 32'd0;
        else if (sample_en)
            phase_acc <= phase_acc + phase_inc;
    end

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync) begin
            addr_n  <= 12'd0;
            addr_n1 <= 12'd0;
            frac    <= 8'd0;
        end else if (sample_en) begin
            addr_n  <= phase_acc[31:20];
            addr_n1 <= phase_acc[31:20] + 12'd1;
            frac    <= phase_acc[19:12];
        end
    end

    BSRAM_ROM u_rom (
        .clk    (clk),
        .addr_a ({wave_sel[0], addr_n}),
        .addr_b ({wave_sel[0], addr_n1}),
        .dout_a (tab_n),
        .dout_b (tab_n1)
    );

    assign diff   = tab_n1 - tab_n;
    assign interp = tab_n + ((diff * frac) >>> 8);

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync)
            wave_out <= 24'sd0;
        else if (sample_en)
            wave_out <= interp[31:8];
    end

endmodule
```

> **⚠ 疑似 bug（待仿真确认）**：`interp` 的有效位只有约 16 位（`tab_n` 16 位 + 插值项），而末尾取 `interp[31:8]` 相当于**再除以 256**，输出幅度会缩到约 1/256。正确做法应是把低 16 位符号扩展成 24 位，例如：
> `wave_out <= {{8{interp[15]}}, interp[15:0]};`
> （DDS 输出的缩放会一路影响 SVF/VCA，建议用单频正弦仿真核对幅度。）

## 六、SVF 模块

### 6.1 功能

采用 Chamberlin 数字状态变量滤波器，同时提供低通、带通、高通输出。

差分方程：
```
low  = low + f × band
high = input - low - q × band
band = band + f × high
```

### 6.2 接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | 输入 | 1 | 系统时钟 |
| `rst_n_sync` | 输入 | 1 | 同步复位 |
| `sample_en` | 输入 | 1 | 采样使能 |
| `audio_in` | 输入 | 24 | 来自 DDS，有符号 |
| `f_coeff` | 输入 | 16 | 频率系数，Q1.15 |
| `q_coeff` | 输入 | 16 | 阻尼系数，Q1.15 |
| `filter_type` | 输入 | 2 | 0=LP, 1=BP, 2=HP |
| `audio_out` | 输出 | 24 | 有符号，送往 VCA |

### 6.3 系数与定点方案

**effective_fc 合成公式**（定点方案）：

```
env_term = (filter_env_depth × env_value) >>> 15;    // 16 位
lfo_term = (filter_lfo_depth × lfo_out) >>> 15;      // 16 位有符号
effective_fc = filter_cutoff + env_term + lfo_term + filter_cutoff_mod;
// 饱和处理：限制在 0 ~ 65535
```

| 信号 | 位宽 | 格式 | 范围 |
|---|---|---|---|
| `filter_cutoff` | 16 | 无符号整数 | 0~65535 |
| `filter_env_depth` | 16 | Q1.15 | 0~1.0 |
| `env_value` | 16 | 无符号 | 0~65535 |
| `filter_lfo_depth` | 16 | Q1.15 | 0~1.0 |
| `lfo_out` | 16 | 有符号 | -32768~32767 |
| `filter_cutoff_mod` | 16 | 有符号 | -32768~32767 |

**系数计算**：
- 频率系数：`f = 2 × sin(π × effective_fc_scaled / fs)`，使用 128 点查找表
- 阻尼系数：`q = 1/Q`，Q1.15 格式

### 6.4 内部位宽与输出

- 内部状态 `low`、`band`、`high`：**32 位有符号**
- 输出：取 `[31:8]`，即 **24 位有符号**

### 6.5 关键代码

```verilog
module svf_voice (
    input  wire        clk,
    input  wire        rst_n_sync,
    input  wire        sample_en,
    input  wire signed [23:0] audio_in,
    input  wire [15:0] f_coeff,
    input  wire [15:0] q_coeff,
    input  wire [1:0]  filter_type,
    output reg  signed [23:0] audio_out
);

    reg signed [31:0] low, band, high;

    wire signed [31:0] f_ext  = {{16{f_coeff[15]}},  f_coeff};
    wire signed [31:0] q_ext  = {{16{q_coeff[15]}},  q_coeff};
    wire signed [31:0] in_ext = {{8{audio_in[23]}}, audio_in};

    wire signed [31:0] f_band = (f_ext * band) >>> 15;
    wire signed [31:0] q_band = (q_ext * band) >>> 15;
    wire signed [31:0] f_high = (f_ext * high) >>> 15;

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync) begin
            low  <= 32'sd0;
            band <= 32'sd0;
            high <= 32'sd0;
        end else if (sample_en) begin
            low  <= low + f_band;
            high <= in_ext - low - q_band;
            band <= band + f_high;
        end
    end

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync)
            audio_out <= 24'sd0;
        else if (sample_en) begin
            case (filter_type)
                2'd0: audio_out <= low[31:8];
                2'd1: audio_out <= band[31:8];
                2'd2: audio_out <= high[31:8];
                default: audio_out <= low[31:8];
            endcase
        end
    end

endmodule
```

## 七、ADSR / VCA 模块

### 7.1 功能

- **ADSR**：产生随时间变化的包络值 `env_value`，含延音踏板（PENDING_RELEASE 状态）。
- **VCA**：将 SVF 输出乘以 `env_value`、`velocity_gain`、`vca_gain`。

### 7.2 接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | 输入 | 1 | 系统时钟 |
| `rst_n_sync` | 输入 | 1 | 同步复位 |
| `sample_en` | 输入 | 1 | 采样使能 |
| `audio_in` | 输入 | 24 | 来自 SVF |
| `gate` | 输入 | 1 | 按键按下=1 |
| `sustain_pedal` | 输入 | 1 | 延音踏板踩下=1 |
| `attack_step` | 输入 | 16 | Attack 每采样增量 |
| `decay_step` | 输入 | 16 | Decay 每采样减量 |
| `sustain_level` | 输入 | 16 | Sustain 目标电平 |
| `release_step` | 输入 | 16 | Release 每采样减量 |
| `velocity_gain` | 输入 | 16 | 力度增益（当前默认 16'h7FFF） |
| `vca_gain` | 输入 | 16 | 音色总增益 |
| `audio_out` | 输出 | 24 | 送往通道混音层 |
| `env_value` | 输出 | 16 | 写回声部状态表 |
| `env_state` | 输出 | 3 | 写回声部状态表 |

### 7.3 状态机（含延音踏板）

状态：IDLE、ATTACK、DECAY、SUSTAIN、PENDING_RELEASE、RELEASE。

**关键转移**：
- SUSTAIN 时若 `gate=0`：
  - `sustain_pedal=1` → PENDING_RELEASE
  - `sustain_pedal=0` → RELEASE
- PENDING_RELEASE 时：
  - `gate=1` → SUSTAIN
  - `sustain_pedal=0` → RELEASE

### 7.4 时间参数换算

时间参数单位：**毫秒**。

```
attack_step = 65536 / (adsr_attack_ms × fs / 1000)
```

例如 `adsr_attack = 125 ms`：
```
attack_step = 65536 / (125 × 48000 / 1000) = 65536 / 6000 ≈ 11
```

### 7.5 VCA 运算

```
voice_out = audio_in × env_value × velocity_gain × vca_gain
```

每一步乘法后右移相应位数归一化。

### 7.6 关键代码

```verilog
module adsr_vca (
    input  wire        clk,
    input  wire        rst_n_sync,
    input  wire        sample_en,
    input  wire signed [23:0] audio_in,
    input  wire        gate,
    input  wire        sustain_pedal,
    input  wire [15:0] attack_step,
    input  wire [15:0] decay_step,
    input  wire [15:0] sustain_level,
    input  wire [15:0] release_step,
    input  wire [15:0] velocity_gain,
    input  wire [15:0] vca_gain,
    output reg  signed [23:0] audio_out,
    output reg  [15:0] env_value,
    output reg  [2:0]  env_state
);

    localparam IDLE            = 3'd0;
    localparam ATTACK          = 3'd1;
    localparam DECAY           = 3'd2;
    localparam SUSTAIN         = 3'd3;
    localparam RELEASE         = 3'd4;
    localparam PENDING_RELEASE = 3'd5;

    reg [15:0] env_next;
    reg [2:0]  state_next;

    always @(*) begin
        env_next   = env_value;
        state_next = env_state;
        case (env_state)
            IDLE: begin
                env_next = 16'd0;
                if (gate) state_next = ATTACK;
            end
            ATTACK: begin
                if (env_value + attack_step >= 16'hFFFF) begin
                    env_next = 16'hFFFF;
                    state_next = DECAY;
                end else
                    env_next = env_value + attack_step;
            end
            DECAY: begin
                if (env_value <= sustain_level + decay_step) begin
                    env_next = sustain_level;
                    state_next = SUSTAIN;
                end else
                    env_next = env_value - decay_step;
            end
            SUSTAIN: begin
                env_next = sustain_level;
                if (!gate) begin
                    if (sustain_pedal) state_next = PENDING_RELEASE;
                    else               state_next = RELEASE;
                end
            end
            PENDING_RELEASE: begin
                env_next = sustain_level;
                if (gate)              state_next = SUSTAIN;
                else if (!sustain_pedal) state_next = RELEASE;
            end
            RELEASE: begin
                if (env_value <= release_step) begin
                    env_next = 16'd0;
                    state_next = IDLE;
                end else
                    env_next = env_value - release_step;
            end
            default: state_next = IDLE;
        endcase
    end

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync) begin
            env_value <= 16'd0;
            env_state <= IDLE;
        end else if (sample_en) begin
            env_value <= env_next;
            env_state <= state_next;
        end
    end

    wire [31:0] gain_vel_vca = velocity_gain * vca_gain;
    wire [31:0] gain_total   = (gain_vel_vca[31:16] * env_value) >> 16;
    wire signed [31:0] audio_ext = {{8{audio_in[23]}}, audio_in};
    wire signed [47:0] result = (audio_ext * gain_total) >>> 16;

    always @(posedge clk or negedge rst_n_sync) begin
        if (!rst_n_sync)
            audio_out <= 24'sd0;
        else if (sample_en)
            audio_out <= result[39:16];
    end

endmodule
```

> **⚠ 疑似 bug（待仿真确认）**：Q1.15 × Q1.15 应**右移 15 位**归一化，但这里两级乘法都用了 16 位移位 —— `gain_vel_vca[31:16]`（等价 `>>16`）和最后的 `>>16`，各多移 1 位，增益整体偏小。

```
#File_format=Hex
```

```
#File_format=Hex

007D    // 钢琴 125 ms
000A    // 吉他 10 ms
```

其他字段同理。

## 十一、资源估算

| 模块 | DSP | BSRAM | 逻辑 |
|---|---|---|---|
| DDS | 1 | 128 Kbit（~7 模块） | ~400 LUT |
| SVF | 3 | 0 | ~500 LUT |
| ADSR/VCA | 2 | 0 | ~300 LUT |
| **单声部合计** | **6** | **~7 模块** | **~1200 LUT** |

32 声部总计：DSP 约 192 个，BSRAM 约 224 个，LUT 约 38400 个。高云 138K 有 298 个 DSP、340 个 BSRAM、138K LUT，资源充裕。

## 十二、注意事项

1. 波表数据为 16 位有符号补码，`-1` 写 `FFFF`，`32767` 写 `7FFF`。
2. 相位累加器不清零，频率切换时保持相位连续。
3. SVF 内部状态 32 位有符号，输出取 `[31:8]` 为 24 位。
4. Q1.15 格式最大值 32767（代表 0.9999），`f_coeff` 和 `q_coeff` 不得超过此值。
5. 时间参数单位统一为毫秒。
6. 延音踏板通过 `sustain_pedal` 和 PENDING_RELEASE 状态实现。
7. 所有 `.mi` 文件修改后需重新生成 BSRAM IP。
8. 扩展音色时，新数据必须追加在波表末尾，不能插入中间。

## 九、扩展方向

1. **力度接入**：在声部分配阶段计算 `velocity_gain`，写入声部状态表。
2. **双波表混合**：DDS 同时查 `wave_main` 和 `wave_aux`，按 `wave_mix` 加权求和。
3. **FM 合成**：在 DDS 中加入调制器，按 `fm_ratio_m`、`fm_depth` 调制相位。
4. **音色扩展**：增大 `wave_sel` 位宽，更新 `.mi` 文件。
5. **声部扩展**：增大 `G`（串行组数），泳道逻辑不变。
