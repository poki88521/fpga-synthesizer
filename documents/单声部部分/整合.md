# 单声部模块移植技术文档

**适用平台：高云 GW5A-138K（Sipeed Tang Mega 138K Pro）**

**系统时钟：50 MHz**

**音频采样率：约 48 kHz（每采样周期 1042 个时钟拍）**

**面向读者：组内负责集成、调试、扩展的成员**

---

## 一、文档目的

本文档说明单声部处理链中 **DDS、SVF、VCA** 三个模块的：

- 模块功能与在系统中的位置
- 接口定义与参数来源
- 相关文件（波表 `.mi`、ADSR 参数表）
- 移植步骤与注意事项

阅读本文档前，请先了解《技术文档.md》中的四层组织、状态表与调度时序。

本文档不考虑鼓组相关逻辑。

## 二、单声部在系统中的位置

单声部处理链位于**单声部处理层**，每个声部独立实例化。

数据流：

```
声部状态表 / 通道状态表 / 音色参数表
                ↓
        DDS → SVF → VCA
                ↓
        通道混音层（通道总线累加）
```

单声部由“声部时序器”产生索引，“声部取数器”预取三张表的上下文，送入本链。

所有模块在 `sample_en`（约 48 kHz 使能）有效时更新。

**时钟与采样率**：

- 系统时钟 `f_clk = 50 MHz`
- 音频采样率 `f_s ≈ 48 kHz`
- 50 MHz 不能被 48 kHz 整除，采用每采样周期固定 **1042 个时钟拍**
- 实际采样率 `50 MHz / 1042 ≈ 47.98 kHz`，与 48 kHz 偏差约 0.04%，对音频无影响
- I2S 的 MCLK/BCLK 按实际采样率配置

## 三、DDS 模块

### 3.1 功能

DDS（直接数字频率合成）负责**生成原始波形样本**。

通过 32 位相位累加器产生数字相位，取高 12 位查波表 ROM，输出 16 位有符号波形样本。

输出频率：

```
f_out = phase_inc × f_s / 2^32
```

### 3.2 接口

| 信号 | 方向 | 位宽 | 来源 / 去向 |
|---|---|---|---|
| `clk` | 输入 | 1 | 系统时钟 50 MHz |
| `rst_n` | 输入 | 1 | 复位 |
| `sample_en` | 输入 | 1 | 48 kHz 使能脉冲 |
| `phase_inc` | 输入 | 32 | 声部状态表 `phase_inc` |
| `wave_sel` | 输入 | 2 | 音色参数表 `wave_main`（低 2 位选音色） |
| `phase_acc` | 输入/输出 | 32 | 声部状态表 `phase_acc`（逐采样更新） |
| `wave_out` | 输出 | 16 | 送往 SVF |

### 3.3 参数来源

| 参数 | 来源表 | 字段 |
|---|---|---|
| 相位增量 | 声部状态表 | `phase_inc` |
| 主波表索引 | 音色参数表 | `wave_main` |
| 辅助波表索引 | 音色参数表 | `wave_aux` |
| 主/辅混合比例 | 音色参数表 | `wave_mix` |

### 3.4 波表文件（`.mi`）

波表以高云 BSRAM ROM 形式存储，初始化文件为 `.mi`（Hex 格式）。

**文件结构**：

多个音色连续存放，每个音色一个完整周期 4096 点，每点 16 位有符号补码。

| 音色 | 地址范围 |
|---|---|
| 音色 0 | 0 ~ 4095 |
| 音色 1 | 4096 ~ 8191 |
| 音色 2 | 8192 ~ 12287 |
| 音色 3 | 12288 ~ 16383 |

**`.mi` 文件头部**：

```
#File_format=Hex
#Address_depth=16384
#Data_width=16
```

**ROM 地址拼接**：

```
rom_addr = {wave_sel[1:0], phase_acc[31:20]}
```

- `wave_sel[1:0]`：2 位音色选择（当前支持 4 种音色）
- `phase_acc[31:20]`：12 位相位索引
- 总地址 14 位

### 3.5 移植步骤

1. **准备波表数据**：从 SoundFont 或免费波表包提取单周期波形，量化为 16 位有符号整数。
2. **生成 `.mi` 文件**：按上述头部格式编写，数据按音色顺序排列。
3. **配置 BSRAM**：在高云 EDA 中打开 IP Core Generator，选择 BSRAM，模式 Read-Only，地址深度 16384，数据宽度 16，加载 `.mi` 文件。
4. **例化 ROM**：将生成的 ROM 模块接入 DDS 逻辑。
5. **连接相位累加器**：确保 `phase_acc` 在 `sample_en` 有效时更新，且不清零（保证相位连续）。

### 3.6 注意事项

- 16 位有符号数必须用补码，`-1` 写 `FFFF`，`32767` 写 `7FFF`。
- 高云 BSRAM 同步读，输出比地址晚一拍，对音频无影响。
- 相位累加器不清零，频率切换时保持相位连续。
- 扩展音色数量时，增大 `wave_sel` 位宽，更新 `.mi` 头部 `Address_depth`。

## 四、SVF 模块

### 4.1 功能

SVF（状态变量滤波器）对 DDS 输出进行**频域塑形**，同时提供低通、带通、高通输出。

采用 Chamberlin 数字结构：

```
low  = low + f × band
high = input - low - q × band
band = f × high + band
```

### 4.2 接口

| 信号 | 方向 | 位宽 | 来源 / 去向 |
|---|---|---|---|
| `clk` | 输入 | 1 | 系统时钟 |
| `rst_n` | 输入 | 1 | 复位 |
| `sample_en` | 输入 | 1 | 48 kHz 使能 |
| `audio_in` | 输入 | 16 | 来自 DDS `wave_out` |
| `filter_type` | 输入 | 2 | 音色参数表 `filter_type` |
| `fc_ctrl` | 输入 | 16 | 合成后的截止频率控制字 |
| `q_ctrl` | 输入 | 16 | 合成后的共振控制字 |
| `audio_out` | 输出 | 16 | 送往 VCA |

### 4.3 参数来源

| 参数 | 来源表 | 字段 |
|---|---|---|
| 滤波器类型 | 音色参数表 | `filter_type`（LP/BP/HP） |
| 基准截止频率 | 音色参数表 | `filter_cutoff` |
| 基准谐振 | 音色参数表 | `filter_resonance` |
| 包络调制深度 | 音色参数表 | `filter_env_depth` |
| LFO 调制深度 | 音色参数表 | `filter_lfo_depth` |
| 截止频率调制 | 通道状态表 | `filter_cutoff_mod` |
| 谐振调制 | 通道状态表 | `resonance_mod` |
| 包络值 | 声部状态表 | `env_value` |
| LFO 输出 | LFO 模块 | `lfo_out` |

**截止频率合成**：

```
effective_fc = filter_cutoff
             + filter_env_depth × env_value
             + filter_lfo_depth × lfo_out
             + filter_cutoff_mod
```

### 4.4 系数计算

**频率系数**：

```
f = 2 × sin(π × effective_fc / fs)
```

**阻尼系数**：

```
q = 1 / Q
```

`f` 和 `q` 可通过查找表预先计算，避免实时做 sin 运算。

### 4.5 内部状态

`filter_ic1`（对应 `low`）和 `filter_ic2`（对应 `band`）存储在声部状态表中，逐采样更新。

使用 **24 位有符号数**防止溢出。

### 4.6 移植步骤

1. **确定系数计算方式**：查找表或 CORDIC。推荐查找表，预先算好 128 个频点的 `f` 值存入 ROM。
2. **例化 SVF 逻辑**：按差分方程实现 `low`、`band`、`high` 更新。
3. **连接状态变量**：从声部状态表读 `filter_ic1`、`filter_ic2`，更新后写回。
4. **连接参数**：从音色参数表、通道状态表、LFO 模块读取调制参数。
5. **选择输出**：根据 `filter_type` 选择 `low`、`band` 或 `high`。

### 4.7 注意事项

- 内部状态必须用 24 位有符号，16 位会溢出。
- 截止频率较高时（> 5 kHz）必须用完整 sin 公式，不能用线性近似。
- `q` 越小共振越强，注意限制范围防止自激。
- 滤波器状态建立需要时间，快速切换截止频率时可能有瞬态。

## 五、VCA 模块

### 5.1 功能

VCA（压控放大器）对 SVF 输出施加 **ADSR 包络增益**，控制音符的音量随时间变化。

当前暂不接入力度，`velocity_gain` 使用默认值；后续加入力度时只需接入计算逻辑。

核心运算：

```
voice_out = filtered × env_value × velocity_gain
```

### 5.2 接口

| 信号 | 方向 | 位宽 | 来源 / 去向 |
|---|---|---|---|
| `clk` | 输入 | 1 | 系统时钟 |
| `rst_n` | 输入 | 1 | 复位 |
| `sample_en` | 输入 | 1 | 48 kHz 使能 |
| `audio_in` | 输入 | 16 | 来自 SVF `audio_out` |
| `env_value` | 输入 | 16 | 声部状态表 `env_value` |
| `velocity_gain` | 输入 | 16 | 声部状态表 `velocity_gain`（当前默认值） |
| `expression` | 输入 | 7 | 通道状态表 `expression` |
| `vca_gain` | 输入 | 16 | 音色参数表 `vca_gain` |
| `audio_out` | 输出 | 16 | 送往通道混音层 |

### 5.3 ADSR 包络

**状态机状态**：

IDLE、ATTACK、DECAY、SUSTAIN、RELEASE。

**参数来源**：

| 参数 | 来源表 | 字段 |
|---|---|---|
| Attack 时间 | 音色参数表 | `adsr_attack` |
| Decay 时间 | 音色参数表 | `adsr_decay` |
| Sustain 电平 | 音色参数表 | `adsr_sustain` |
| Release 时间 | 音色参数表 | `adsr_release` |
| 包络曲线 | 音色参数表 | `adsr_curve` |
| Attack 调制 | 通道状态表 | `attack_mod` |
| Release 调制 | 通道状态表 | `release_mod` |
| 延音踏板 | 通道状态表 | `sustain_pedal` |
| 按键状态 | 声部状态表 | `gate` |
| 待释放标记 | 声部状态表 | `pending_release` |

**时间参数换算**：

```
attack_step = 65536 / (adsr_attack × fs)
```

例如 `adsr_attack = 10 ms`，`fs = 48000`：

```
attack_step = 65536 / (0.01 × 48000) ≈ 137
```

每个采样周期 `env_value += attack_step`，直到 65535。

### 5.4 ADSR 参数表（音色相关文件）

不同音色的 ADSR 典型值：

| 音色 | Attack | Decay | Sustain | Release | 物理原因 |
|---|---|---|---|---|---|
| 钢琴 | 较长（~125 ms） | 中等 | 低（0.2~0.4） | 中等 | 琴槌击弦后能量持续衰减 |
| 吉他 | 极短（< 30 ms） | 短 | 极低 | 短 | 拨弦瞬间注入能量 |
| 贝斯 | 短 | 中等 | 中 | 短 | 拨弦+琴体共振 |
| 小提琴 | 中等（50~150 ms） | 短 | 高（0.8~1.0） | 中等 | 弓持续摩擦弦 |

**参数获取方式**：

1. **SoundFont 提取**：`.sf2` 文件中每个乐器携带音量包络发生器值。
2. **合成器手册**：Roland、Yamaha 等厂商设备说明书。
3. **实测分析**：对真实乐器录音，在音频软件中测量包络曲线。
4. **自定义设计**：创造非标准音色时自行设定。

### 5.5 力度预留

当前无力度要求，`velocity_gain` 使用默认值（建议 `16'h7FFF`，约等于 1.0）。

预留接口：

- 声部状态表已有 `velocity` 与 `velocity_gain` 字段。
- 音色参数表已有 `vel_sensitivity` 字段。
- 后续加入力度时，在声部分配阶段计算：

```
velocity_gain = f(velocity, vel_sensitivity)
```

写入声部状态表，VCA 直接读取，无需改动核心逻辑。

### 5.6 移植步骤

1. **实现 ADSR 状态机**：IDLE → ATTACK → DECAY → SUSTAIN → RELEASE。
2. **时间参数换算**：将 `adsr_attack` 等时间参数换算为每采样步进值。
3. **例化乘法器**：使用高云 DSP 单元（18×18），右移 16 位还原量程。
4. **连接状态变量**：从声部状态表读 `env_value`、`env_state`，更新后写回。
5. **连接包络参数**：从音色参数表、通道状态表读取。
6. **力度预留**：`velocity_gain` 当前接默认值，后续接入计算逻辑。

### 5.7 注意事项

- 包络曲线 `adsr_curve` 可选线性或指数，指数更接近真实乐器。
- 时间参数换算时注意整数除法精度，可用移位近似。
- 延音踏板 `sustain_pedal` 影响 RELEASE 状态转移。
- 力度当前为默认值，预留字段，后续接入无需改动 VCA 核心。

## 六、模块集成

### 6.1 顶层连接

```
dds_voice u_dds (
    .clk, .rst_n, .sample_en,
    .phase_inc, .wave_sel,
    .phase_acc, .wave_out
);

svf_voice u_svf (
    .clk, .rst_n, .sample_en,
    .audio_in (wave_out),
    .filter_type, .fc_ctrl, .q_ctrl,
    .audio_out (svf_out)
);

vca_voice u_vca (
    .clk, .rst_n, .sample_en,
    .audio_in (svf_out),
    .env_value, .velocity_gain, .expression, .vca_gain,
    .audio_out (voice_out)
);
```

### 6.2 状态表连接

| 模块 | 读声部表 | 读通道表 | 读音色参数表 |
|---|---|---|---|
| DDS | `phase_acc`、`phase_inc` | `bend_ratio`、`vibrato_depth` | `wave_main`、`wave_aux`、`wave_mix` |
| SVF | `filter_ic1`、`filter_ic2` | `filter_cutoff_mod`、`resonance_mod` | `filter_type`、`filter_cutoff`、`filter_resonance`、`filter_env_depth`、`filter_lfo_depth` |
| VCA | `env_value`、`env_state`、`gate`、`pending_release` | `attack_mod`、`release_mod`、`sustain_pedal` | `adsr_attack`、`adsr_decay`、`adsr_sustain`、`adsr_release`、`adsr_curve`、`vca_gain` |

### 6.3 时序

所有模块共用 `sample_en`（约 48 kHz），在有效时更新。

声部由“声部时序器”产生索引，“声部取数器”预取上下文。

固定时隙保证确定性无抖动延迟。

**时钟与采样率**：

- 系统时钟 50 MHz
- 每采样周期固定 1042 拍
- `sample_en` 每 1042 个时钟产生一个脉冲
- 实际采样率约 47.98 kHz
- I2S 主时钟按此配置

## 八、移植检查清单

- [ ] 波表 `.mi` 文件头部与 BSRAM 配置一致（深度 16384、宽度 16）。
- [ ] 16 位数据为补码格式。
- [ ] 相位累加器不清零，频率切换相位连续。
- [ ] SVF 内部状态为 24 位有符号。
- [ ] 截止频率系数 `f` 使用查找表或 CORDIC。
- [ ] ADSR 时间参数已换算为每采样步进值。
- [ ] VCA 乘法使用 DSP 单元，右移 16 位。
- [ ] `velocity_gain` 当前接默认值，预留接口。
- [ ] 所有模块共用 `sample_en`（每 1042 拍一个脉冲）。
- [ ] 单声部输出送入通道混音层。

## 九、扩展方向

1. **力度接入**：在声部分配阶段计算 `velocity_gain`，写入声部状态表。
2. **双波表混合**：DDS 同时查 `wave_main` 和 `wave_aux`，按 `wave_mix` 加权求和。
3. **FM 合成**：在 DDS 中加入调制器，按 `fm_ratio_m`、`fm_depth` 调制相位。
4. **音色扩展**：增大 `wave_sel` 位宽，更新 `.mi` 文件。
5. **声部扩展**：增大 `G`（串行组数），泳道逻辑不变。
