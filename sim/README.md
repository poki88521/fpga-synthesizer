# 模块三 Demo

这是「通道处理层 + 全局处理层」（我负责的板块）的全链仿真 demo。

## 文件

| 文件 | 说明 |
|---|---|
| `tb_full_chain.v` | 全链 testbench：自建 8 个音符当输入，跑完整条链并导出音频 |
| `wav.py` | 把仿真导出的文本转成 WAV（**纯演示辅助，和芯片无关**） |
| `run_demo.sh` | 一键：编译 → 仿真 → 转 WAV |
| `out/demo.wav` | **导出的音频**，可以直接播 |
| `out/demo.txt` | 中间产物，每行 `左 右` 两个 16-bit 有符号整数 |

## 怎么跑

```sh
sh demo/run_demo.sh
```

仿真很慢（约 1 秒音频要跑几分钟），因为链路上每个采样要几百个时钟。

## 链路

```
8 个音符（模拟单声部层输出，P=8 泳道 x G=4 时隙）
    │
    ▼  通道处理层        chan_buf / chan_coef / chan_layer
16 条通道的立体声（已含音量 x 表情 x 声像）
    │
    ├──────────────► 效果发送总线  send_bus
    │                      │
    │                      ▼  效果器运算  fx_top
    │                 fx_reverb / fx_chorus / fx_delay
    │                      │
    ▼                      ▼  效果返回
    主混音求和  main_mix（16 通道 + 效果返回）
    │
    ▼  主输出处理  master_chain
主音量 → 隔直 → 抖动 → 24→16bit → PT8211 串行
```

## ⚠️ 当前状态（诚实版）

**能用的部分** —— 里程碑 1/2/3，每个都有通过的 testbench 在 `sim/` 下：

```
PASS  tb_norm_sat      归一化+饱和，2000 组随机对比参考模型
PASS  tb_dc_block      隔直（直流收敛/交流保幅，与金标准一致）
PASS  tb_pt8211_tx     BCLK ÷32、WS 每 16 拍翻转、左右字顺序全对
PASS  tb_master_chain  从串行 DAC 流解码出 440.0 / 879.8 Hz
PASS  tb_chan_layer    通道处理层，96 次通道比对全部一致
PASS  tb_mix_chain     发送总线 + 主混音，24 次比对全部一致
```

**还没搞定的部分**：

1. **全链 demo 大约在 6000 个样本处静音**，根因还没定位。
   门控信号此时是全开的，所以不是包络问题，是链路在那里停了。
2. **实测每采样约 2000~5000 拍，设计估算约 235 拍，慢了近一个数量级。**
   这个数字很可能和上一条是同一个根因。
3. **效果器（`fx_reverb` / `fx_chorus` / `fx_delay`）还没有独立的 testbench。**
   目前只到「能编译、能连进全链跑」的程度，没到「逐项验证」的程度。
4. `fx_top` 里「三个效果都回报完成才输出」的握手逻辑要重写 ——
   实验证明用 `REV_EN=0` 旁路混响时它会把返回时序搞乱（那次实验结果因此不算数）。
