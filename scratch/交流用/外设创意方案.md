## 一、演奏界面：**无弦之琴**

### 概念

**没有琴弦的竖琴。**

八道肉眼不可见的红外光刃，横列在你面前。手穿过去——**光断了，音就响了**。

弦是看不见的，所以看起来像是"隔空拨动了空气"。

```
        ║      ║      ║      ║      ║      ║      ║      ║
        ║      ║      ║      ║      ║      ║      ║      ║
   1    2      3      4      5      6      7      8
   Do   Re     Mi     Fa     Sol    La     Si     Do
```

### 三个维度，一个动作

| 你做的事 | 乐器听到的 |
|---|---|
| 手穿**哪道光** | 弹哪个音 |
| 光**断了** | 音头（触发） |
| 手**扫得多快** | 力度 |

**拨得越快，光断得越短，音就越响。** —— 这不需要额外传感器，
因为"快"这个动作本身就写在光被遮住的时长里。

### 延展玩法

**滑奏**：手横扫过全部八道光 → 音阶像瀑布一样流下来。

**光刃渐隐**：手慢慢探进光里（不完全遮断）→ 音色悄然渐弱。
因为光敏管是模拟量，**遮挡的深浅也是一维信息**——这是隐藏的第四维。

### 硬件

红外发射管 ↔ 光敏三极管，一槽一对。手是"弦槌"。
支架开八道 15 mm 的槽——**像一把竖琴，只是琴弦换成了光**。

## 二、表情控制：**磁戒指**

### 概念

**戴一枚磁戒指。**

左手食指套一个小磁铁，在霍尔传感器上方移动——
**音高就在空气中滑走。**

```
        ┌───────────────┐
        │   ↑ 升高半音   │
        │   〇           │  ← 磁戒指悬在这里
        │   ↓ 降低半音   │
        └───────────────┘
             霍尔传感器
```

### 两个维度，都藏在距离里

| 手的位置 | 控制 |
|---|---|
| **横向移动** | 滑音（pitch bend）——像吉他推弦 |
| **靠近/远离** | 颤音深度 —— 手一抖，音就颤 |

**"距离"同时是音高和表情。** 一个传感器两维，且完全无接触——
演奏时手里那点微小的抖，会变成音乐的呼吸。

### 为什么好看

评委看到的是：**演奏者捻动手指，琴音随之滑走，手指一颤，声音跟着颤抖**。
没有旋钮、没有踏板——**音乐是从手势里长出来的**。

## 三、可视化：**把声音画出来**

### 3.1 频谱：**呼吸的火焰**

64 点灯带，32 段频谱。

不是冷冰冰的柱子——**每根柱子像烛火**：
有能量时窜高、有余晖时缓慢落回。低频橙红、高频青蓝，
**整条灯带像一团在呼吸的火**。

### 3.2 音高：**彩虹音阶**

每个音有自己的颜色。

```
Do 红 ─ Re 橙 ─ Mi 黄 ─ Fa 绿 ─ Sol 青 ─ La 蓝 ─ Si 紫 ─ Do 红
```

**弹琴时，灯带在流动。** 八度循环回到红色——
**颜色本身就在讲"音阶"这件事**，不懂乐理的人也能看懂。

### 3.3 波形 × 李萨如：**声音的肖像**

单声道时画**波形**（一条跳动的线）；
一旦左右声道不同（比如开了合唱/混响），自动切换成**李萨如**——
**声音在平面上画出一个会旋转变形的结**。

不同的音色，画出不同的图形：
正弦是一个圆，方波是一个方框，混响是一团慢慢散开的雾。
**这是"音色"最直观的样子。**

### 3.4 演奏指引：**跟着灯走**

```
● ● ● ○ ○ ○ ○ ○      ← 灯依次亮起，你跟着弹
  ↑
 现在弹这里
```

弹对了 → 灯**亮白**；弹偏了 → 灯**闪红**。

## 四、脱机模式：**会教你的乐器**

### 4.1 课桌模式

插上电，不接电脑，灯带自己亮起——

```
═══════════════════════════════
   ●                              ← 当前该弹的音
   ○○○○                            ← 后面四个音在路上
═══════════════════════════════
```

**像节拍器，但教的是旋律。**

### 4.2 留痕模式 —— 最有意思的部分

**它记住你弹的每一个音。**

演奏结束后按一下按钮，灯带把刚才的演奏**重画一遍**：

```
← 时间
████ ▓▓▓ ░░░ ████ ▓▓ ░░░░░ ███   ← 亮度 = 力度
      ↑         ↑
   这里偏了    这里很好
```

**你的演奏变成一条发光的热迹。**
哪里轻了、哪里抢拍了，一眼就看出来——**这是一面带记忆的镜子。**

### 4.3 曲线模式

连续弹一百个音，灯带自动画出**你的力度曲线**：

```
力度
127 ┤        ╭─╮
    │    ╭───╯ ╰╮
 64 ┤ ╭──╯       ╰──╮
    │╱               ╰─
   0 └──────────────────→ 时间
```

**看着自己的手感在变化。** 越练越稳，这条线就越平。
