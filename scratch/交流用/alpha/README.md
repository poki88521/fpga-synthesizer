# 可视化 alpha —— 接真音频，演奏即出波形

> 2026-10-19 · alpha 目标：**你一弹，屏上就出现真实波形。**

## 一、改了什么（只有 3 处，都是加法）

| 文件 | 改动 | 逻辑增量 |
|---|---|---|
| `full_top.v` | 加 2 个输出 `mon_l`/`mon_r` + 2 条 `assign` | **0**（只是把已有 wire 引出去） |
| `full_system.v` | 加 6 个 LCD 端口 + 例化 `vis_top` + 1 条 wire 声明 | 1 个例化 |
| `.cst` / `.sdc` | 追加 22 个引脚 + 4 条 false_path | 约束 |

**音频通路一行没动**：`master_chain`/`soft_limiter`/声部层全部原样。
tap 点用 `sample_l`（本来就连到 `pt8211_tx`），**不新增任何寄存器**。

## 二、怎么用

1. **替换**：`full_top.v`、`full_system.v` 用本目录的版本
2. **新增**到工程：`rtl/pll_pixel.v`、`rtl/lcd_800x480.v`、`rtl/vis_audio.v`、`rtl/wave_render.v`、`rtl/vis_top.v`
3. **约束**：`full_system_add.cst` 追加到 `full_system.cst` 末尾；`full_system_add.sdc` 同理
4. 综合 → P&R → 烧录 → 弹琴

## 三、应该看到

- 有声音就有波形（青色，11 px 粗线，纯黑底，白零轴 3 px，白框 2 px）
- 音高越高，屏上周期越密
- 响度越大，波形越高（满幅上下各留 40 px 天地）
- 波形**不乱抖**（每帧从上升过零点起画）

## 四、已知限制（beta 补）

| # | 限制 | 原因 |
|---|---|---|
| 1 | 颜色固定青色 | 还没接 8 音色混色 |
| 2 | 窗口固定 1024 采样，高音偏密 | 还没做自适应八度缩放 |

## 五、上板前留意

- **P&R 后必须看时序**：基线是 0 违例 / +0.022 ns，加了 22 个 IO + 一个新时钟域，要看新报告
- 预计增量：LUT +4~5 K、BSRAM +9、DSP +1~2（都远低于余量）
- 面板按 800×480 做的；若是黑的/花的，改 `H_FP/H_BP/V_FP/V_BP`（480×272 用 50/30/20/5）+ `pll_pixel` 的 `ODIV0=100`

## 六、仿真验过的

| 项 | 结果 |
|---|---|
| 帧周期 | 635336 拍 = 1192×533，刷新 55.09 Hz |
| 像素对齐 | 逐像素比对，0 失配 |
| 线宽 / 零轴 / 白框 / 黑底 | 11 px / 3 px / 2 px / 纯黑 |
| **440 Hz 正弦驱动** | 屏上 9.4 个周期（=1024×440/48000，与理论一致） |

## 七、踩过的坑

| # | 坑 | 现象 |
|---|---|---|
| 1 | `buf` 是 Verilog 门原语关键字 | 编译语法错 |
| 2 | 对 `parameter integer` 位选 | iverilog 给 X → 整屏黑 |
| 3 | `acc_use[19:8]` 越界 | 地址变 X → 整屏黑 |
| 4 | TB 的 `sample_stb` 写成电平 | 重复写 1024 次 → 显示直线 |
| 5 | RGB666 满量程是 63 不是 7 | 颜色只有 11% 亮度 |
