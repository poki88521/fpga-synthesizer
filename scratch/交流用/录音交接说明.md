# 录音交接说明（给 sakiko）

> 2026-10-20
> 用途：把 FPGA 板子的**模拟音频输出**录进电脑，做成 wav，供离线分析。
> 我们这边正在定位"低音区炸、高音区正常"这个 bug，需要真实录音来确认假设。

---

## 一、我们需要什么

### 1. 核心目标

**录到**板子耳机口的真实模拟输出**，用来做频谱分析。**

**最关键的一条：录音必须**不削顶、不经过任何音效处理**，否则分析出来的东西全是录音链路的失真，白费。**

### 2. 具体要的文件

**同一个会话里连续录完，中间**不要动任何音量**：**

| 内容 | 时长 | 说明 |
|---|---|---|
| **静音基准** | 5 秒 | 板子不发任何音（panic 后）—— 用来量底噪 |
| **C2（低音）** | 2~3 秒 | 最低的测试音，问题最严重 |
| **C4（中音）** | 2~3 秒 | 中间参考 |
| **C6（高音）** | 2~3 秒 | 这个区域据听感是正常的，做对照 |
| **再一段静音** | 3 秒 | 确认底噪没有漂移 |

**合计约 20 秒，一个 wav 文件即可。**

### 3. 文件格式

```
wav，16 位（或 24 位），**48000 Hz**，单声道或立体声都行
```

**48000 Hz 很重要** —— 板子的采样率就是 48 kHz，用别的采样率会引入重采样，频谱会有偏移。

### 4. 同时请告知

```
· 录音时板子的通道音量设成了多少（cc 7 的数值）
· 用的是哪个输入端（粉色麦克风口 / USB 声卡 / 其他）
· 录音峰值大概到多少 dB
```

## 二、接线

```
板子 J29（3.5mm 耳机口，CTIA 四极）
   ↓  3.5mm 公对公线
电脑 粉色麦克风口（3 极 TRS 独立麦克风输入）
```

**⚠️ 三个必须注意的点：**

**① 只能用耳机口（J29），绝对不要从功放引线**

板子上有一个 XPT4809 class-D 功放（推喇叭）。**它是 BTL 桥接输出，任一端接地都会短路，可能烧功放。**
耳机口经过 LMV321 缓冲，是标准的单端输出，可以安全接电脑。

**② 板子会检测耳机插入**

板子有 `HP_DET` 耳机检测 + 模拟开关（BL1551），**插上耳机后喇叭会自动静音、信号切到耳机口** —— 这是正常行为。

**所以插上线后喇叭不响是预期的。判断信号在不在，要看录音端。**

**③ 插头的匹配**

板子是 CTIA 四极孔，普通线是三极 TRS。**理论上 L/R/GND 能对上**，但如果录不到信号，试着把插头**往外拔一点点（约 1 mm）** —— 有些插座的簧片位置对不齐。

## 三、电脑端设置（这几项不改，录了也没用）

### 1. 麦克风属性（`Win+R` → `mmsys.cpl` → 录制 → 双击麦克风）

**"级别" 标签**

```
麦克风音量    = 10~20（不要更高）
麦克风加强    = **0 dB**（很多机器默认 +20 或 +30 dB，一开就削顶）
```

**"增强" 标签**

```
☑ **禁用所有声音效果**
   （尤其是"噪声抑制"和"回声消除" —— 它们会滤掉低频，
     而我们要分析的低频成分正好在 50 Hz 以下，被滤掉就白录了）
```

**"高级" 标签**

```
默认格式 = **48000 Hz**
☐ 不要勾"允许应用程序独占控制该设备"
```

### 2. 录音软件（Audition 或 Audacity）

```
采样率 = 48000 Hz
位深   = 16 位或 24 位
输入   = **Mic in at front panel (Pink)**
         （千万不要选 "麦克风 (…-Camera)" 那个是摄像头自带的）
```

**校准电平的步骤：**

```
1. 板子静音 → 录 5 秒 → 电平表应接近 -∞（-60 dB 以下）
2. 弹一个音 → 调整电平，让**峰值落在 -12 dB 左右**
   · 到 0 dB（红了）= 削顶 → 降低 Windows 麦克风音量，或让板子把音量调小
   · 低于 -30 dB = 太小 → 提高板子音量
3. 定好之后**不要再动任何音量**，接着录 C2 / C4 / C6
```

### 3. 怎么确认没削顶

**把录音波形放大看顶部：**

```
圆滑的弧顶  = 正常
一条平直的横线 = 削顶，这次录音作废，降低增益重录
```

## 四、一个 30 秒的自检（建议先做）

**在正式录音前，用 Windows 自带的"侦听"功能确认线是通的：**

```
mmsys.cpl → 录制 → 麦克风 → "侦听" 标签
  → 勾选"侦听此设备"，输出到扬声器
  → 播放板子的声音
     · 电脑音箱能听到 → 线通了 ✓
     · 听不到 → 线/接口/设备选择有问题，先解决再录
  → 测完**记得取消勾选**（否则会啸叫）
```

## 五、为什么要这些（背景，方便你判断）

**我们现在的症状是：**

```
· 上电的自检音（32 条谱线）完全干净
· 一弹音就"炸"（噪音感）
· **C6（1047 Hz）以上听起来正常，C6 以下全是噪音**
· 与音量、力度、panic 都无关
· 效果器全关也炸
```

**我们的假设是：**滤波器（SVF）的积分器在定点运算下累积了直流偏差，产生低频垃圾，**正好污染低音区**，高音区远高于这个频率所以听不出来。

**录音能验证：**

```
· C2 的录音里如果 < 50 Hz 的能量远高于 C6 → 假设坐实
· 如果削顶了 → 波形顶部是平线，能一眼看出来
· 如果录音链路的"噪声抑制"误开了 → 低频被滤掉，会误判成"没有低频问题"
```

**所以第三节那几项设置**必须**照做 —— 尤其是"禁用所有声音效果"。**
