# 模块速查表

> **用途**：FPGA 开发时快速查阅各模块的接口、作用以及注意事项。
> **依据**：`技术文档.md`（模块清单、读表清单、事件时序、数据流）、`硬件实现.md`（时钟与复位）。
> **范围**：只写「输入 / 输出 / 职责 / 涉及的表」，**不涉及内部算法与实现原理**——那些归各自模块负责人。
> **表内字段的位宽与含义**见 `技术文档.md` §四。
> **复位后状态**一列对应 `硬件实现.md` §二 的复位情况表。
>
> **注**：本表属**组内交流**材料，非正式文档；原 §八（开发注意点）/ §九（待定项）/ §十（硬件实现细节）已并入 `技术文档.md` 与 `硬件实现.md`，此处不再保留。

## 一、模块总览

按四层组织。**触发方式**决定模块是否在逐采样路径上。

| 层 | 模块 | 触发 |
|---|---|---|
| 调度层 | MIDI 消息解析 | 事件 |
| 调度层 | 通道状态表编辑器 | 事件 |
| 调度层 | 音色映射 | 事件 |
| 调度层 | 声部分配 / 释放器 | 事件 |
| 调度层 | 声部时序器 | 周期 |
| 调度层 | 声部取数器 | 周期 |
| 单声部处理层 | DDS + 波表 | 周期 |
| 单声部处理层 | ADSR 包络 | 周期 |
| 单声部处理层 | SVF 滤波器 | 周期 |
| 单声部处理层 | VCA | 周期 |
| 通道处理层 | 通道总线累加 | 周期 |
| 通道处理层 | 通道增益 | 周期 |
| 通道处理层 | 通道声像 | 周期 |
| 通道处理层 | 效果发送 | 周期 |
| 全局处理层 | 混响 / 合唱 / 延迟 | 周期 |
| 全局处理层 | 主混音求和 | 周期 |
| 全局处理层 | 主输出处理 | 周期 |
| 全局处理层 | I2S 发送 | 周期 |

> **事件**：消息到达时工作，不在逐采样路径上。
> **周期**：每采样周期工作，须在时钟预算内完成（`N_cyc = 1024` 拍）。

## 二、调度层

### 事件类

| 模块 | 输入（来源） | 输出（去向） | 涉及的表 | 职责 | 复位后状态 |
|---|---|---|---|---|---|
| **MIDI 消息解析** | MIDI 字节流<br>（乐器端口 ×3、混音器端口） | 通道消息 → 通道状态表编辑器<br>Note On/Off → 声部分配器 | — | 解析字节流、区分消息类型并分发；**丢弃乐器端口的混音类 CC** | 状态机回 IDLE；运行状态缓存清零 |
| **通道状态表编辑器** | 通道消息<br>（CC、Program Change、Bank Select、Pitch Bend、RPN） | 写通道状态表 | 写：通道状态表 | 维护通道状态表 | 待写缓冲清空 |
| **音色映射** | `(bank_msb, program)`<br>（来自通道状态表） | `timbre_slot` → 声部分配器 | 读：音色映射表 | 把 MIDI 音色号映射为内部音色槽 | 无状态（查表） |
| **声部分配 / 释放器** | Note On/Off<br>`timbre_slot`（来自音色映射） | 写声部表<br>「已分配 / 已释放」标记 → 声部时序器 | 读：通道状态表（`note_count`、`max_voices`）<br>写：声部表（分配类字段） | 声部分配、抢断、释放 | 无待处理事件；分配状态清零 |

### 周期类

| 模块 | 输入（来源） | 输出（去向） | 涉及的表 | 职责 | 复位后状态 |
|---|---|---|---|---|---|
| **声部时序器** | 分配器标记 | 声部索引 `(组, 泳道)` → 声部取数器 | — | 产生声部索引与轮转节拍（不含取数逻辑） | 计数器归零，与采样边界重新对齐 |
| **声部取数器** | 声部索引 | 声部上下文 → 单声部处理层 | 读：声部表（运行状态）、通道状态表、音色参数表<br>写：声部表（运行状态） | 按索引并行取出声部上下文；预取下一时隙参数以隐藏读延迟 | 预取寄存器置无效 |

> **两者关系**：分配器不直接改写计算路径正在使用的字段，而是通过标记通知时序器。

## 三、单声部处理层

**每个声部一份实例**（`P` 条泳道 × `G` 个串行组）。声部上下文由声部取数器提供，各模块**自身不直接读表**（表读取集中在取数器）。

| 模块 | 输入 | 输出（去向） | 职责 | 复位后状态 |
|---|---|---|---|---|
| **DDS + 波表** | 声部上下文：`phase_acc`、`phase_inc`、`note`、`timbre_slot`<br>调制：`bend_ratio`（通道表） | 波形样本 → SVF 滤波器 | 生成基础波形 | `phase_acc` 归零 |
| **ADSR 包络** | 声部上下文：`env_value`、`env_state`、`gate`、`pending_release`<br>通道表：`attack_mod`、`release_mod`、`sustain_pedal` | 包络值 → VCA<br>（另调制 SVF、DDS） | 产生包络，控制音量与调制 | `env_state` → IDLE；`env_value` = 0 |
| **SVF 滤波器** | 声部上下文：`filter_ic1`、`filter_ic2`<br>通道表：`filter_cutoff_mod`、`resonance_mod`<br>调制：ADSR 滤波包络 | 滤波后样本 → VCA | 滤波（平滑化） | `filter_ic1` / `filter_ic2` 归零 |
| **VCA** | 滤波后样本<br>包络值（来自 ADSR）<br>`velocity_gain`、`expression` | 声部音频 → 通道总线累加 | 施加包络与力度（= 包络 × 力度） | 无状态（纯运算） |

> **注意**：`volume` 与声像**不在本层**，它们在通道处理层施加。

## 四、通道处理层

**按通道（16 个）**，每采样 16 次。

| 模块 | 输入 | 输出（去向） | 涉及的表 | 职责 | 复位后状态 |
|---|---|---|---|---|---|
| **通道总线累加** | 各声部音频<br>声部所属通道号 | 通道音频 → 通道增益 | 读：声部表（`channel`） | 把声部并入所属通道（16 条总线） | 累加器清零 |
| **通道增益** | 通道音频（来自总线累加） | → 通道声像 | 读：通道状态表（`volume`、`expression`） | 施加通道音量与表情 | 无状态（纯运算） |
| **通道声像** | 通道音频（来自通道增益） | L/R → 主混音求和<br>另抽出 → 效果发送 | 读：通道状态表（`pan`、`pan_gL`、`pan_gR`） | 施加声像 | 无状态（纯运算） |
| **效果发送** | 通道音频（来自通道声像） | 3 条发送总线 → 效果器 | 读：通道状态表（`send_reverb`、`send_chorus`、`send_delay`） | 按发送量抽出湿信号 | 无状态（纯运算） |

## 五、全局处理层

**单实例**（全项目各一份）。

| 模块 | 输入 | 输出（去向） | 涉及的表 | 职责 | 复位后状态 |
|---|---|---|---|---|---|
| **混响 / 合唱 / 延迟** | 3 条发送总线（来自效果发送） | 效果返回 → 主混音求和 | 读：效果参数表 | 效果运算（**运算在 FPGA 内**） | 延迟线清零 |
| **主混音求和** | 16 条通道 + 效果返回 | → 主输出处理 | — | 汇总为立体声主输出 | 累加器清零 |
| **主输出处理** | 主混音（来自求和） | → I2S 发送 | 读：主输出参数表 | 主音量、限幅、抖动 | 限幅器状态复位 |
| **I2S 发送** | 主输出音频（内部 24 bit） | I2S 信号（BCLK / LRCK / DIN）→ DAC（PT8211） | — | 48 kHz / **16 bit** / **LSBJ 格式**（见 `硬件实现.md` §四） | 停止移位输出 |

## 六、接口与边界

| 位置 | 名称 | 说明 |
|---|---|---|
| 板外 → FPGA | **乐器端口 ×3** | 每个端口 I2C / MIDI 二选一；进 FPGA 前统一转为 MIDI |
| 板外 → FPGA | **混音器端口** | **独立接口**；全部消息进混音/控制路径 |
| FPGA → 板外 | **I2S** | BCLK / LRCK / DATA → DAC |
| 板外 | **DAC → 功率放大 → 输出设备** | 模拟链路 |

**输入侧规则**
- 乐器端口的**混音类 CC（7 / 10 / 91 / 93 / 94）直接丢弃**
- 混音器端口提供：`volume`、`pan`、`send_reverb`、`send_chorus`、`send_delay`、效果参数、主音量

## 七、表清单速查

| 表 | 规模 | 可变性 | 读它的模块 | 写它的模块 |
|---|---|---|---|---|
| **通道状态表** | 16 项 | A / B | 通道状态表编辑器（写）、取数器、通道增益、通道声像、效果发送、分配器 | 通道状态表编辑器 |
| **声部状态表** | N 项（`N = P × G`） | B / C | 取数器 | 分配器（分配类字段）、取数器（运行状态） |
| **音色参数表** | 槽数 × 一项 | A | 取数器、音色映射 | 启动载入 |
| **效果参数表** | 13 字段 | B | 混响 / 合唱 / 延迟 | 混音器（SysEx） |
| **主输出参数表** | 4 字段 | B | 主输出处理 | 混音器（SysEx） |
| **音色映射表** | `[bank][program]` | A | 音色映射 | 启动载入 |
| **波表** | 采样点数 × 位宽 | A | DDS | 启动载入 |

**可变性**：A = 只读（综合/启动载入）；B = 事件驱动写；C = 逐采样读写。
