> **状态：待定。** 下表列出三个候选方案供讨论，尚未选定。

**LFO 的作用**：不发声的**低频调制源**（0.1~20 Hz），三种用途——颤音（调制音高）、震音（调制音量）、滤波扫描（调制截止）。

**字段分布的矛盾**：

| 字段 | 所在表 | 暗示层级 |
|---|---|---|
| `lfo_freq` / `lfo_wave` / `filter_lfo_depth` | 音色参数表 | 逐音色 → **声部级** |
| `lfo_delay` / `lfo_fade` | 音色参数表 | **per-note 概念** → **声部级** |
| `mod_wheel`(CC1) / `vibrato_depth` | 通道表 | 通道消息 → **通道级** |
| `lfo_phase` | 声部表 | **声部级**（现状） |

**关键约束**：`lfo_delay`（按下后延迟起振）与 `lfo_fade`（深度渐增）都需要「**这个音被按下的时刻**」作起点。若 LFO 提到通道级，通道级不知道各音何时按下 → **语义丢失**。

**「同通道不同声部是否需要不同 LFO」分两层**：

| 层面 | 是否 per-note |
|---|---|
| **相位**（波形走到哪） | 可共享（键盘合成器习惯：通道内同步）或独立（更接近真实弦乐） |
| **延迟 / 淡入**（何时开始、多深） | **必然 per-note**（后按的音要重新计时） |

**三个方案对比**：

| 方案 | 相位 | delay/fade | 成本 | 评价 |
|---|---|---|---|---|
| A 全声部级 | 各音独立 | 完整 | N 份相位累加 + **P 路并发查表** | 最真实、最贵 |
| B 全通道级 | 通道内同步 | **丢失** | 16 份 | 最省，但 `lfo_delay`/`fade` 白写 |
| C 混合 | 通道内同步 | 完整 | 16 份波形 + N 份 fade 乘法 | 折中 |

**方案 C 结构**：

```
通道级（16 份）：
    lfo_phase 累加 + 波形查表  →  lfo_wave_out（同通道声部共享）

声部级（N 份）：
    fade_env：按下后先等 lfo_delay，再按 lfo_fade 斜升至 1
    实际调制量 = lfo_wave_out × fade_env × (音色表深度)
```

**方案 C 的额外好处**：LFO 波形**查表**同样有「多泳道并发读」问题（与波表同理）。
放声部级需要 **P 路并发**；放通道级只需 16 份（且可时分）——又省一份 BRAM 端口压力。

- 接受 → 方案 C
- 不接受 → 方案 A（代价：P 路并发查表）
