## 一、基础要求

### 1. 多维交互控制检测（≥2 个独立可控维度，自研交互方案）

| 项 | 内容 |
|---|---|
| 条款原文 | "自主设计演奏交互形态，基于各类传感器实现演奏动作精准采集，支持选音、触发、拨弦、力度感应等操作，具备至少2个独立可控维度" |
| 我们的实现 | **传感器侧由 majiao 负责（进行中）**；FPGA 侧输入为 MIDI（4 路 UART），传感器只需转成 MIDI 字节即可接入 |
| 可演示的维度 | 力度（vel）、表情（CC11）、截止（CC74）、谐振（CC71）、起音（CC73）、颤音（CC1）、弯音（Pitch Bend）——**≥2 维已满足** |
| 实测方法 | 逐维改参数，录音对比 |
| 期望结果 | 每个维度都有独立可辨的变化 |
| 实测结果 | ⬜ |

### 2. 纯硬件实时合成 + 延迟 ≤10 ms

| 项 | 内容 |
|---|---|
| 条款原文 | "完整音频生成通路全部基于FPGA HDL硬件逻辑实现……控制信号到音频输出总延迟≤10ms" |
| 我们的实现 | 全链路 RTL：`wave_fetch`（波表取数）→ `dds_voice`（DDS 插值）→ `svf_voice`（状态变量滤波）→ `adsr_vca`（包络+VCA）→ `chan_layer`（通道增益/声像）→ `fx_top`（混响/合唱/延迟）→ `main_mix` → `master_chain`（限幅/去直流/抖动）→ `pt8211_tx`（I2S） |
| 预取/流水设计 | 三级预取（`voice_fetch` stage A/B/C）+ 逐帧时隙调度（4 时隙 × 8 泳道，帧 20.8 µs） |
| 实测方法 | ① 仿真 `simulation/tb/tb_poly_latency.v` 算理论值；② 上板双通道示波器：CH1 接 MIDI 输入、CH2 接 C24（SD 探针）量到音频起始 |
| 期望结果 | ≤10 ms（理论：帧 20.8 µs × 数帧 + MIDI 3 字节 ≈ 1~2 ms） |
| 实测结果 | ⬜ |

### 3. 合规实时发声与多复音（≥4，逐样本、实时变调、ADSR、多声部混音、禁预录）

| 项 | 内容 |
|---|---|
| 我们的实现 | 32 复音 ✔；ADSR（`adsr_vca`）✔；多声部混音（`chan_layer`/`main_mix`）✔；**单音实时变调 = 弯音/颤音**（`chan_table` 查表插值 → `voice_fetch.apply_ratio` → 每帧刷新 `pf_phase_inc`） |
| 禁预录 PCM 的证据 | 波表每个槽**只有 1 个周期、2048 点**（`wave_table/out/wave_table.hex`），DDS 逐样本相位累加 + 线性插值生成波形；无任何 PCM 流存储或播放逻辑 |
| 实测方法 | 同时按 4/8/16/32 个音；`bend`/`cc 1` 验证实时变调；ADSR 用 `cc 73`/`cc 72` 改起音/释放 |
| 期望结果 | 32 音并发不破不卡；弯音连续滑动（±2 半音）；颤音周期性抖动（±1 半音） |
| 实测结果 | ⬜ |

## 三、核心评分规则

| 规则 | 我们的情况 | 证据 |
|---|---|---|
| **振荡器统计**：独立振荡器 = 独立相位累加器 + 频率调控 + 包络控制；单波表查表不计谐波 | 32 个声部各自满足三条；一个声部只查一张表、只算 1 个振荡器（**不虚报**） | `dds_voice.v`（`phase_r[4]`）、`voice_fetch.v`（`pf_phase_inc`）、`adsr_vca.v`（`env_r[4]`） |
| **吞吐量**：活跃振荡器数 × 实际采样率，过采样不叠加 | 32 × 48 kHz = **1.536 M/s** | 时钟 49.152 MHz / 1024 = 48 kHz 帧率 |
| **现场验证**：测试模式可观测对应数量独立谱峰 + RTL 佐证 + 证明无预录 | 测试模式 32 振荡器（未实测）；RTL 可现场翻看；波表单周期 | `test_voice_gen.v`、`wave_table/out/wave_table.hex` |
