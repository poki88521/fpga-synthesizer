# 二、⭐ 当前的核心 bug：**音高精确高了 2 倍**（已确认，仿真+实板一致）

## 2.1 证据（三次测量，全部 2.00 倍）

```
仿真 note 60（C4，期望 262 Hz）→ 最强峰 **524.5 Hz**   比值 2.00
实板 C4（示波器 CSV，120 ms）  → 最强峰 **525.0 Hz**   比值 2.01
实板 C6（示波器 CSV，60 ms）   → 最强峰 **2100.0 Hz**  比值 2.01
```

**而且基频**还在**，只是弱于八度分量：**

```
C4：262 Hz 幅度 78，525 Hz 是最强峰（高 7.0 dB）
C6：1047 Hz 幅度 35，2100 Hz 最高（高 9.7 dB）
```

**能量分布印证：**

```
C4：  20~200 Hz   5.8%      ← 基频所在，几乎没能量
      200~1000    32.6%
      1000~3000   42.9%     ← 八度分量主导
      3000~8000   18.7%
C6：  1000~3000   36.4%
      3000~8000   48.6%
```

## 2.2 已定位到的环节（今天刚查到）

**① DDS 相位推进是**正确的**：**

```
[帧1] phase_acc 563320277 → 加 23409859 (slot=0)     ← 只有 slot 0 加满
[帧1] phase_acc 586730136 → 加 0        (slot=1)
[帧1] phase_acc 586730136 → 加 0        (slot=2)
[帧1] phase_acc 586730136 → 加 0        (slot=3)
```

**→ 每帧只推进一次，加满 23409859 = 261.6/48000 × 2³² ✓ 正确**

**② 但 `samples_rdy` **每帧触发 4 次**（应为 1 次），且**前 2 次的数据没稳定**：**

```
帧2: samples_rdy 触发 4 次
   dds_out=4777984   phase_acc=633549854  idx=302
   dds_out=4982272   phase_acc=633549854  idx=302   ← 相位相同，输出却不同
   dds_out=4965632   phase_acc=633549854  idx=302   ← 稳定
   dds_out=4965632   phase_acc=633549854  idx=302   ← 稳定

帧3:
   dds_out=4965632   ← 上一帧的残留值
   dds_out=5192960   ← 过渡值
   dds_out=5196288   ← 稳定
   dds_out=5196288   ← 稳定
```

**③ 推断：4 个采样里 2 个是未稳定的错值，2 个正确。若下游按"每帧 2 个采样"使用 → 音高翻倍 + 宽带失真。**

**这正是"炸"的来源。**
