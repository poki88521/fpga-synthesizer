## 4. 关键代码事实（重构前必读）

```
fx_reverb.v 参数：NL=20（li 0..15 梳状，16..19 全通）、SLOT=4096、AW=24
   梳状长度 1215~1637（2026-10-28 从 1215~2879 收短，为了省布线资源）
   右声道 = 左声道 + 25
   梳状注入：bl <= sat24(((bus_l * size) + 2^22) >>> 23)      ← ÷256 + 四舍五入
   comb_sum_n = comb_sum + {{24{m0[AW-1]}}, m0}              ← 16 条直接累加
   li==15 时：ap_x = sat24(comb_sum_n >>> 1)                  ← 求和后 ÷2
   4 级全通（单位增益）
   出口：ret_l <= sat24((ap_out_lp * p_ret) >>> 15)           ← 2026-10-26 加的 (1,2,1)/4 高切
   当前常数（full_top.v）：size=26000 decay=31000 damping=14000 return=26000
                          chorus_rate=300 depth=20000 mix=23000(0.70!) delay_fb=15000 return=9000
```

## 5. 增益预算表（按此设计，不要试听调参）

| 节点 | 目标峰值 | 实现 |
|---|---|---|
| 单声部 | 0.6 FS | 力度 127 |
| 效果发送总线 bus | ≤0.9 FS | CC91 控制 |
| 梳状注入（每条） | ≤0.0035 FS | ÷256 |
| 梳状稳态（decay 0.946 → ×18.5） | ≤0.065 FS | |
| 16 条非相干求和（×4） | ≤0.26 FS | |
| 求和归一（当前 >>1） | ≤0.13 FS | |
| 全通（×1） | ≤0.13 FS | |
| **wet 返回** | **≤0.35 FS** | 反推 p_ret |
| 干 0.6 + 湿 0.35 | **≤0.95 FS** | 留 5% 余量 |

**按此表算，当前 `>>1` + `p_ret=26000` 理论上 wet ≈ 0.10 FS（约 −20 dB）——不可能"炸"。**
⇒ 所以"炸"更可能是**结构性错误**（某处少归一化 / 位宽不足 / 某条梳状长度越界 / 反馈单向累积），
   必须靠**仿真量化**找出来，而不是按表调常数。

## 8. 爆音（症状 B）：另一个独立问题，候选名单

```
① SD 调制器（pt8211_tx）输入≈0 时的空闲极限环（1 位 SD 经典问题）
② dc_block 低频极点极限环
③ dither16 的两个 16 位 LFSR 拍频（周期 65535 样本 ≈ 1.37 s）
判别：**量爆音周期**
   · ≈1.37 s → dither16
   · 几 Hz~几十 Hz → dc_block / SD 空闲环
   · 与 48 kHz 整除 → 调度/帧相关
⛔ 手上 4 段录音（note-on/off × reverb-on/off，在 material/audio）未能可靠量出周期：
   手机 AGC 使绝对电平不可信；我的瞬态聚类窗口(10ms)会截断真实周期 → 改用自相关
⇒ 需要一段"纯空载、混响关、10 秒"的录音
```
