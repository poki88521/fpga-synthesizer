# 弯音（Pitch Bend）接入 —— 暂缓说明

2026-10-15 撤下 board 的原因：**接入 `rd_bend_ratio` 后 `chan_table` 出现严重时序违例**
（Setup Violated Endpoints 566 → 1092，最差 slack -5.909 ns 落在 `u_sched/u_ct`），
导致通道参数读出可能出错 → 听感上"完全无声"。

## 撤掉了什么

- `voice_fetch.v` 的 `input wire [15:0] bend_ratio` 端口
- `voice_fetch.v` 的 `note2inc(note, bend)`（弯音乘法 + `>>14`）
- `sched_subsystem.v` 里 `.bend_ratio(ct_bend_ratio)` 的接线

撤掉后 `ct_bend_ratio` 重新成为"未使用信号"，综合器会把整条
`B_BRATIO` 查表插值链（含两个乘法器 + BRAM 读）优化掉，时序恢复正常。

## 备份文件

- `scratch/agent/voice_fetch_弯音版备查.v`
- `scratch/agent/sched_subsystem_弯音版备查.v`

## 重新启用前必须先解决

1. **给 `bend_tbl` 查表插值加流水线**（现在是一个周期内做完：22 位减法+乘法、
   `>>>5`、加法、BRAM 读 ×2、又一次乘法、加法 —— 太长了）
2. 或者**降低查表精度**（减少插值位宽）
3. **弯音的"重算活跃声部 V_PHINC"路径**（目前只对新分配的音生效）还没做

## chan_table.v 的复位值保留

`B_BRATIO = 16384`（Q2.14 的 1.0）/ `B_BVALUE = 8192` / `B_BRANGE = 2` 这三处复位值
**保留在代码里**（是正确性修复，字段未使用时会被综合优化掉，不影响时序）。
