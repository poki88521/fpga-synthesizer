# 使用手册（Tang Mega 138K Pro / FPGA 合成器）

板卡 GW5AST-LV138FPG676A｜clk50=P16(50M) clk12288=N22(24.576M)
系统时钟 49.152 MHz（PLL，USE_PLL=1）｜采样率 48 kHz｜复音 32（8 泳道×4 时隙）｜音色 8

| 功能 | 引脚 | 说明 |

| MIDI 入 3 | A17 | 混音口：**CC7/10/91/93/94 只此口生效** |

| LED/调试 | M25 L20 N21 R26 | dbg_led；IIC K25/K26；mux N19 P19 P26 |

## 模式
- **测试模式**：上电自动进入，32 个对数振荡器 200 Hz~8 kHz（核心评分用）；发任一 Note On 退出。
- 效果/主音量参数：`EXT_FXPARAM=0`（内置默认）、`MVOL_EXT=1`（主音量走 SysEx），见 full_system.v。
- 限幅器/去直流/抖动常开。

## MIDI（31250 8N1，字节间隔建议 ≥3.2 ms）
- PC 0~7 → 音色槽 0~7（先发 Bank MSB CC0 + LSB CC32 再 PC）。
- CC1 颤音 ±1 半音｜CC11 表情｜CC71 谐振｜CC72 释放｜CC73 起音｜CC74 截止
- CC91/93/94 混响/合唱/延迟发送（仅 A17）｜CC7 音量、CC10 声像（仅 A17）
- CC120 立即断音 / CC123 温和关音（全通道）
- 弯音 En ll mm：中心 8192，±2 半音
- SysEx 主音量：`F0 7F 7F 04 01 ll mm F7`（14 位，16383=满；内部 8 档，6 dB/档）
