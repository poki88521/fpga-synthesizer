# 交接：和弦“震荡感”定位与波表修正（2026-11-02）

## 一句话结论

**“和弦震荡感” = 等律大三度的 5:4 近似导致的 10.3 Hz 拍频，被波表槽 0 过强的 4 次分音放大。**
**不是 RTL bug**，已按最小改动修改 `data/wave_table.hex` 的槽 0。

## 证据链（实测数字）

| 项 | 数值 | 来源 |
|---|---|---|
| 理论拍频 | `\|5×261.6256 − 4×329.6276\| = 10.38 Hz` | C4/E4 音高 |
| 录音中的两根谱线 | 1308.17 Hz（C4 5F）、1318.50 Hz（E4 4F），相距 10.33 Hz | `material/audio/fpga-record-10.wav` 细谱（0.17 Hz 分辨率） |

## 为什么 4F 会异常强（−8.1 dB = 39%，而 `full_system.v` 注释写 13.3% = −16.2 dB）

`develop/wave_table/rebuild_wave_table.py` 用的是“**谐波量化重合成**”：
把源里每个 bin 折到最近的整数谐波 `h = round(k/P)`。而脚本第 23–25 行自己记录：
**piano 有 12.8% 能量在 bin7（= 3.5 个基频周期）**，`round(3.5) = 4`
⇒ 这部分**非谐波能量被折进了 4 次分音**，4F 因此被抬高到 −8.1 dB。

真实钢琴不会这么“干净地拍”：钢丝有**不谐和性**（`f_n = n·f₀√(1+Bn²)`）+ 同音 2~3 根弦微失谐，
会把拍频揉成柔和合唱。波表合成是完美整数谐波 + 零失谐 ⇒ 拍频特别规整、特别显。
（调律师本来就靠“数大三度的拍频”调琴，所以这个现象本身是**音乐上真实的**。）

## 已做的修改（最小改动档）

改 `develop/board/full_system/data/wave_table.hex` 与 `develop/wave_table/out/wave_table.hex`：

- **只动槽 0（钢琴）的 2048 行**，其它 7 个槽**逐行逐字节不变**（回读校验：槽外改动行 = 0）
- 把 **5 次分音衰减 11 dB**（−24.6 → −35.6 dB），并把峰值归一化回 31831（响度不变）
- 文件字节数、换行符（CRLF / LF）均保持原样
- 备份：`*.bak_20261102_2210`

依据：包络纹波幅度 = `2·min(a₅F, a₄F)`，当前 `min` 就是 5F
⇒ **只压 4F 反而让相对拍频更深，必须压 5F**。

效果（算术预期）：
```
拍频纹波  0.1172 → 0.0330（−11 dB）
相对 4F 载波   30% → 8%
槽0 RMS   18640 → 18373（−0.13 dB，音色几乎不变）
峰值      31831 → 31831
```

## 候选假设的排除记录（都做过定量核对，勿重复踩）

| 假设 | 结论 | 依据 |
|---|---|---|
| ① 相位增量量化失谐 | 排除 | 32 位相位增量误差 0.01 ppm（要凑 1 Hz 拍频需 3822 ppm）；`apply_ratio` 在 ratio=16384 时逐位精确（仿真实测 `pf_phase_inc=0x016534C3` 与 `note_inc[60]` 相等） |
| ② ch_lfo 底值 | 排除 | `mod_wheel` 复位 0 ⇒ `depth=0` ⇒ `ch_vib_ratio` 恒 16384 |
| ③ SVF 状态截断 | 排除 | 稳态只剩谐波失真；实测调制只出现在 1308/1318 这一对分音上，与滤波器无关 |
| ④ 增益步进 | 排除 | 逐位复刻 `chan_coef` 平滑：vol=100/exp=127 第 2457 次访问精确收敛到 25400，末 2000 次访问纹波 **0 LSB**；访问率 3.072 MHz ÷ 48 kHz = 64（整数） |
| 削顶/限幅 | 排除 | `soft_limiter` THRESH=0x600000=0.75 FS，0.205 FS 下 `g_cur=32768` ⇒ 逐位透明 |
| 混响 | 排除 | 16 梳(1215~1637 点)+4 全通的固定 LTI 网络，不产生拍频；用户实测混响大小不影响 |

**结构性论据**：稳态下整条链（DDS→SVF→VCA→chan_buf/累加→常数 gL→send_bus→固定延迟 fx→main_mix→master_chain）
是 **LTI**，LTI 对两音和弦只能产生“近重合分音拍频”，结构上不可能产生“固定频率、与音高无关”的调制。

## 一个重要教训：现有录音不能用于数字域取证

`develop/material/audio/*` 全部是 **手机 .m4a（AAC）**：

- record10 只有 65 kbps，频谱在 **15.5–16 kHz 有硬砖墙**，16 kHz 以上噪声底掉到 −123 dB
- 整体频响被麦克风/扬声器向 1.3–2 kHz 抬了约 30 dB（record10 里 5F 比 1F 高 36 dB，与波表完全不符）
- 里面那个**间距恒为 68.1 Hz（= f(E4)−f(C4)）的边带梳**、以及 200–2000 Hz 带的 67.4 Hz 振幅调制，
  **不能归罪于 FPGA**（很可能是扬声器/手机过载）
- “record10 峰值 0.205 FS”是**手机满刻度**，不是 FPGA 的 FS

⇒ 以后要判数字域，请抓 **BCK/WS/DIN**（逻辑分析仪 3 根线，1.5 MHz）或 `dbg_sd` 的 1-bit 流。
