**led_test.v**

> - **LED5（N22）**：设计未驱动；`N22` 实为时钟输入 `USR_CLK_IN`（见 §二 H2），与 LED 无关。

> **MS5351 / USR_CLK_IN 实测结论（2026-10-05）**
> - **I2C 从地址 = `0xC0`**（MS5351M 手册原文 8'b1100 000X，同 Si5351A），正确。
> - **可通 mux 档位 = 3**（SEL2/1/0 = 0/1/1）：该档位下从机正常 ACK、配置全部被接受。
> - **根因**：`USR_CLK_IN` 源自 MS5351 的 **CLK2**（不是 CLK0）。此前只配/使能了 CLK0，故 N22 从未被驱动（那 ≈16 MHz 是 **CLK2 的默认输出**；扫描版一开始 `Reg3=0xFF` 把默认 CLK2 也关掉，N22 即成**悬空杂波**）。
> - **配置要点**：MS2（0x3A–0x41）分频 → 目标频率；`Reg18(0x12)=0x4F`（CLK2/MS2/PLLA/8mA）；**`Reg187(0xBB)=0xD0`（fanout 使能，关键）**；`Reg3=0xFB`（只使能 CLK2）；PLLA VCO = 786.432 MHz。
> - **副产物**：PMOD0（N17/N26 等）为 **SSPI/配置专用脚，不能当普通 IO**；**PMOD1/2 可用**。
> - **示波器/端口验证**：`src/test/pin_test/` 在 PMOD2 八脚输出已知频率均正常 → **示波器、探头、PMOD2 端口均可用**。

> **PLL / 最终时钟链实测结论（2026-10-06，`src/test/pll_test/`）—— 成功**
> - **结论：`MS5351 → N22 → FPGA PLL → 49.152 MHz` 打通**，PLL 锁定（`led_lock` 亮）；
>   实测 PMOD2：N22 直通 = 24.5 MHz、clk_49m÷2 = 24.5 MHz、÷16 = 3.07 MHz、÷256 = 192 kHz（均与设计一致）。
> - **最终时钟方案（与 `硬件实现.md` §2.2 现记的 12.288×4 **不同**，待文档更新）**：
>   MS5351 CLK2 输出 **24.576 MHz** → N22 → PLL(`IDIV=1,FBDIV=1,MDIV=32,ODIV0=16`) → **49.152 MHz**。
> - **⚠️ 该 PLL 的实际参数范围（工具报错 PA2078/PA1019 给出，与 DS1104 表 3-18 的 10~400 / 800~2000 **不符**，以工具为准）**：
>   **PFD 19 ~ 81.25 MHz**、**VCO 650 ~ 1300 MHz**。
>   ⇒ `PFD = FCLKIN/IDIV` 且 `IDIV ≥ 1`，故 **FCLKIN 必须 ≥ 19 MHz** → **12.288 MHz 不能直接喂该 PLL**（这是改用 24.576 的原因）。
> - **原语使用要点**：`CLKOUT0_EN="TRUE"` 之外，**动态使能脚 `ENCLK0` 必须接 `1'b1`**（接 0 会报 `PA2146`）。
> - **`N22` 走通用布线**（`PR1014`），PLL 仍能锁定；`clk_in` 的 SDC 周期须与 PLL 的 `FCLKIN` 一致（否则 `TA1118`）。

## 六、PT8211 关键规格（参考资料）

> 来源：`material/PT8211 V1.7_E.pdf`（一手资料）

| 项 | 规格 |
|---|---|
| 格式 | **LSBJ（Japanese / LSBJ）**，two's complement，**MSB first** |
| 锁存沿 | DIN 在 **BCK 上升沿**锁入 → 数据应在 **BCK 下降沿更新** |
| WS 极性 | **低 = 右声道，高 = 左声道**（实测确认，见 H9） |
| 位数 | 只取自 MSB 起**前 16 位**，多余截断 |
| BCK 上限 | **18.4 MHz**（正文提到 20 MHz） |
| WS 上限 | **384 kHz** |
