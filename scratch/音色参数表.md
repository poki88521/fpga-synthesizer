## 字段打包顺序（拼接从高位到低位）

```
{ f_coeff, q_coeff, filter_type, adsr_curve,
  attack_step, decay_step, sustain_level, release_step }
```

```
f_coeff        截止基准，Q1.15 的 sin(π·fc/48000)；30000 ≈ 17.7 kHz
q_coeff        阻尼基准，Q1.15；**越小谐振越强**；32000≈无谐振 / 4000≈强谐振
filter_type    0=低通 1=带通 2=高通
adsr_curve     0=线性 1=指数（目前 8 槽**全部 0**）
attack_step    起音步长，每采样加这个值（越大越快）；attack = 32768/step 采样
decay_step     衰减步长，同上
sustain_level  持续电平，Q1.15（0 = 无持续）
release_step   释放步长（单位：每采样）
               adsr_curve=0（**当前全部**）：线性 env -= release_step
                   释放时间 ≈ env_at_release / release_step 采样
               adsr_curve=1（指数）：env -= (release_step×env)>>15
                   时间常数 τ = 32768/release_step 采样，衰减到 1% 约 4.6τ

另有第 9 个参数（不在 tp_of 的 100 位里）：
vca_gain       每音色输出增益 Q1.15（32768=1.0，最大 65535=2.0），在 vg_of()
```

**截止频率对照**

```
17.7k→30000  12k→23170  8k→16384  6k→12540  5k→10520
4k→8480      3k→6393    2.5k→5340 2k→4277   1.5k→3211  1k→2143
```

### 指数化方案（`adsr_curve = 1`，2026-10-28 供试听）

> 目标：把三个包络段都改成**指数曲线**（听感更接近真实乐器），**时长基本保持不变**。
> 换算规则：指数式衰减到 ~1% 需要 `4.6 × 32768 / step` 采样，
> 因此 `step_exp ≈ 4.6 × step_linear`。

| 槽 | 线性 a/d/r（现用） | **指数 a/d/r（建议）** | 起音(ms) 线性→指数 | 衰减(ms) | 释放(ms) |
|---|---|---|---|---|---|
| 0 电钢琴 | 2 / 1 / 1 | **9 / 17 / 6** | 341 → 349 | 183 → 185 | 500 → 523 |
| 1 吉他 | 341 / 3 / 2 | **1569 / 18 / 38** | 2 → 2 | 172 → 174 | 83 → 83 |
| 2 管风琴 | 1 / 1 / 1 | **5 / 22 / 6** | 683 → 628 | 141 → 143 | 542 → 523 |
| 3 长笛 | 17 / 3 / 2 | **78 / 35 / 15** | 40 → 40 | 89 → 90 | 208 → 209 |
| 4 Pad | 11 / 1 / 2 | **51 / 14 / 14** | 62 → 62 | 224 → 224 | 229 → 224 |
| 5 铜管 | 137 / 7 / 4 | **630 / 83 / 30** | 5 → 5 | 38 → 38 | 104 → 105 |
| 6 弦乐 | 34 / 3 / 2 | **156 / 35 / 15** | 20 → 20 | 89 → 90 | 208 → 209 |
| 7 拨弦 | 682 / 14 / 1 | **3137 / 64 / 1** | 1 → 1 | 49 → 49 | 0 → 3140 |

```
对照：线性 释放 = sustain/release_step 采样；指数 释放 = 4.6×32768/release_step 采样
     线性 起音 = 32768/attack_step 采样； 指数 起音 = 4.6×32768/attack_step 采样
```

**试听时**：把 8 个槽的 `adsr_curve` 全设为 1，填入上表「指数」那一列的 a/d/r，
其余参数（截止/阻尼/类型/持续/增益/波表）保持不变，与线性版 A/B 对比。

## 附：波表实测（2026-10-28，**按 int16 补码读**，这是正确读法）

> ⚠ **数值约定（重要）**：`wave_table.hex` 每行是 **16 位补码位模式的十六进制**
> （例如 `EC91` = −4975），**不是**"无符号中心 32768"。
> 生成脚本必须输出 `(v_signed) & 0xFFFF`，否则波形会在 32768 边界上极性翻转、
> 听感变成"电子味/失真"。2026-10-28 网页端发现并修正过这个问题。

```

1   31147  20174      137        0.0    吉他（重建）
2   32767  14354      345        0.1    管风琴（1 周期，含较强低次）
3   32767  19746      102       -1.4    长笛
4   30000  17320       59        0.0    **与槽 6 几乎完全相同**（旧表重复）→ 已被新 Pad 取代
5   24000  24000    48000       23.4    **原值就是一个幅度 24000 的方波**（RMS=峰值、跳变=2×峰值）
                                         ⇒ 这就是"太电子"的真正原因，不是格式问题
```
