## 字段打包顺序（拼接从高位到低位）

```
{ f_coeff, q_coeff, filter_type, adsr_curve,
  attack_step, decay_step, sustain_level, release_step }
```

```
f_coeff        截止基准，Q1.15 的 sin(π·fc/48000)，30000 ≈ 17.7 kHz
q_coeff        阻尼基准，Q1.15；**越小谐振越强**，22000≈无谐振 / 4000≈强谐振
filter_type    0=低通 1=带通 2=高通
adsr_curve     0=线性 1=指数（目前全部线性）
attack_step    32768 / (起音秒 × 48000)，越大越快，最小 1
decay_step     (32768 − sustain) / (衰减秒 × 48000)
sustain_level  持续电平，Q1.15（0~32768）
release_step   sustain / (释放秒 × 48000)，越大越快，最小 1
```

**截止频率对照**

```
17.7k→30000  12k→23170  8k→16384  6k→12540  5k→10520
4k→8480      3k→6393    2.5k→5340 2k→4277   1.5k→3211  1k→2143
```

## 现场调参（不改代码）

`CC71/72/73/74` 是在上表基准值上**叠加偏移**，64 = 不偏移：

```
CC74  截止   越大越亮
CC71  谐振   越大谐振越强（q_coeff 减小）
CC73  起音   越大起音越慢（attack_step 减小）
CC72  释放   越大释放越慢（release_step 减小）
```

**先用 CC 把方向试出来，再一次性改表里的数值**（改表要重新综合 + P&R，约 30 分钟）。

## ⚠ 现状核实（2026-10-24，以此为准）

> 本文件正文（2026-10-19 的"推算起点"：风琴/钟琴/Pad/铜管、弦乐/打击）是**设计意图**，


### 三条结论

1. **槽 0/1 才有"采样感"**（10-22 重建过）；槽 2~7 是旧合成波形，只是滤波/包络把它们塑造成不同性格。
2. **槽 4/5 没有正式名字** —— 指令手册 §3 里原来空着，2026-10-24 补成"旧合成波 + 柔和木管感 / 强谐振带通"。
3. `vca_gain` 仍是写死 1.0（不读音色表）；`filter_env_depth` 已于 2026-10-24 加了第一版
   （截止随包络下降，起音亮、尾音暗）。
