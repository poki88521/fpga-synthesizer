## 1. 冒烟测试（30 秒，先确认能出声）

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 panic
#  ⚠ CC7 在乐器口上会被 midi_filter 丢掉（只有混音口 port3 才生效），
#    所以冒烟用 CC11（表情）：它和 CC7 在同一个增益级，效果等价。
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 100
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2
```

**正常表现：** 一个中等音量的 C4，有起音和衰减。

**完全没声音 → 立刻停下，先查：**

```
· 串口对不对
· 板子烧的位流是不是最新的
· 耳机/喇叭有没有插对
· 上一轮是不是还挂着 panic 状态
```

## 2. 音高范围（从低到高，每个 2 秒）

**循环版（一次弹完六个音）：**

```powershell
$notes = @{
    24="C1"; 36="C2"; 48="C3"; 60="C4"; 72="C5"; 84="C6"; 96="C7"
}
foreach ($n in 36,48,60,72,84,96) {
    Write-Host "=== $($notes[$n]) (note $n) ===" -ForegroundColor Cyan
    python midi\midi_serial.py -p $P --byte-gap 320 note $n 100 --hold 2
    Start-Sleep -Milliseconds 500
}
```

**单条版（一条一个音，想弹哪个复制哪条）：**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 note 36 100 --hold 2    # C2   65 Hz

python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2    # C4  262 Hz
python midi\midi_serial.py -p $P --byte-gap 320 note 72 100 --hold 2    # C5  523 Hz
python midi\midi_serial.py -p $P --byte-gap 320 note 84 100 --hold 2    # C6 1047 Hz
python midi\midi_serial.py -p $P --byte-gap 320 note 96 100 --hold 2    # C7 2093 Hz
```

**记录：每个音能不能听出音高、有没有失真、失真从哪个音开始。**

## 3. 八个音色（Program Change）

**循环版（一次听八个音色）：**

```powershell
$timbre = @{
    0="钢琴"; 1="吉他"; 2="管风琴"; 3="长笛"
    4="槽4"; 5="槽5"; 6="槽6（锯齿强谐振）"; 7="槽7（拨弦）"
}
foreach ($pc in 0,1,2,3,4,5,6,7) {
    Write-Host "=== 音色 $pc : $($timbre[$pc]) ===" -ForegroundColor Cyan
    python midi\midi_serial.py -p $P --byte-gap 320 pc $pc
    python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2
    Start-Sleep -Milliseconds 500
}
```

**单条版（先切音色，再弹一个音；想听哪个复制哪两行）：**

```powershell
# —— 槽 0 钢琴 ——
python midi\midi_serial.py -p $P --byte-gap 320 pc 0
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 1 吉他 ——
python midi\midi_serial.py -p $P --byte-gap 320 pc 1
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 2 管风琴 ——
python midi\midi_serial.py -p $P --byte-gap 320 pc 2
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 3 长笛 ——
python midi\midi_serial.py -p $P --byte-gap 320 pc 3
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 4（旧合成波 + 柔和木管感）——
python midi\midi_serial.py -p $P --byte-gap 320 pc 4
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 5（旧合成波 + 强谐振带通）——
python midi\midi_serial.py -p $P --byte-gap 320 pc 5
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 6（锯齿强谐振）——
python midi\midi_serial.py -p $P --byte-gap 320 pc 6
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2

# —— 槽 7（拨弦）——
python midi\midi_serial.py -p $P --byte-gap 320 pc 7
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 2
```

**重点听：**

```
· 槽 0~3 = majiao 的真实采样（钢琴/吉他/管风琴/长笛）
· 槽 4~7 = 旧的合成波形
· 两者差别应该很明显
```

**回到默认音色：**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 pc 0
```

## 4. 音强（音量）/ 力度

> ⚠⚠ **端口注意（2026-10-22 查明，非常重要）**
> `rtl/scheduler/midi_filter.v:139` 有一句硬性过滤：
> ```verilog
> wire m_mixcc_drop = (msg_port != 2'd3) && is_mix_cc(m_cc);
> //   is_mix_cc = CC7 / CC10 / CC91 / CC93 / CC94
> ```
> ⇒ **CC7、CC10、CC91、CC93、CC94 只在「混音口」(port 3 = A17 / PMOD2_IO3) 生效；
>    在乐器口（当前 C21 / PMOD2_IO0）上会被直接丢掉，发了等于没发。**
> ⇒ 想在乐器口上调音强，**请用 CC11（表情）**：它没被过滤，且和 CC7 在同一个增益级
>    （`chan_coef.v` 里 `gch = vol × expr`），效果等价。
> ⇒ 音符 / Program Change / 弯音**不受端口影响**，挪线之后照常能弹。

### 4.1 单条版：音强（复制一行改参数即可）

**A. 用 CC11 调音强（乐器口即可，推荐）**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 127    # = 1.0   满
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 90     # ≈ −3 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 64     # ≈ −6 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 32     # ≈ −12 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 8      # ≈ −24 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 2      # ≈ −36 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 0      # 静音
```

**B. 用 CC7 调音强（必须先把 MIDI 输入接到 A17 / PMOD2_IO3）**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 127     # 满
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 64      # ≈ −6 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 32      # ≈ −12 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 8       # ≈ −24 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 2       # ≈ −36 dB
python midi\midi_serial.py -p $P --byte-gap 320 cc 7 0       # 静音
```

**C. 一条命令「设音量 + 按住一个音」**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 cc 11 32; python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 3
```

**D. 力度（另一条路，与音强无关）**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 note 60 127 --hold 2   # 最响
python midi\midi_serial.py -p $P --byte-gap 320 note 60 64  --hold 2
python midi\midi_serial.py -p $P --byte-gap 320 note 60 1   --hold 2   # 最轻
```

### 4.3 力度扫描（循环版）

```powershell
foreach ($v in 1,20,64,100,127) {
    Write-Host "--- 力度 $v ---" -ForegroundColor Cyan
```

### 4.4 效果器开关（必须 port 3 / A17）

```
CC91 = 混响发送    CC93 = 合唱发送    CC94 = 延迟发送
三个都设 0 → 湿声返回为 0。这是判断「炸是不是效果器造成的」的关键测试。
```

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 cc 91 0
python midi\midi_serial.py -p $P --byte-gap 320 cc 93 0
python midi\midi_serial.py -p $P --byte-gap 320 cc 94 0
python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 3
```

⚠ 注意：`test_mode`（上电自检音）本身就会把三路效果返回**强制置零**，
所以"测试模式干净"**不能**作为排除效果器的依据。

## 6. 复音 / panic

### 6.1 panic（清掉所有发声）

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 panic
```

**⚠️ panic 对**测试模式的自检音无效** —— 测试模式完全绕过 MIDI，自检音会一直响到断电。这是设计使然。**

### 6.2 32 复音压测

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 panic
for ($i = 36; $i -lt 68; $i++) {
    python midi\midi_serial.py -p $P note $i 100
}
Start-Sleep -Seconds 2
python midi\midi_serial.py -p $P panic
```

**期望：32 个音同时响，不应该有明显卡顿或爆音。**

### 6.3 快速连打（看有没有累积问题）

```powershell
for ($i = 0; $i -lt 10; $i++) {
    python midi\midi_serial.py -p $P --byte-gap 320 note 60 100 --hold 1
    Start-Sleep -Milliseconds 300
}
```

## 8. 延迟（单次事件）

> 本节只给"发单次事件"的指令；时间差怎么量由测试工具负责（示波器 / 图形化测试网页）。

**单次 Note On（不带 `--hold`，音会一直响，便于对齐起始沿）**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 panic
python midi\midi_serial.py -p $P --byte-gap 320 note 60 127
python midi\midi_serial.py -p $P --byte-gap 320 panic          # 收尾
```

**连续 10 次单音（量抖动用，间隔 500 ms）**

```powershell
foreach ($i in 1..10) {
    python midi\midi_serial.py -p $P --byte-gap 320 note 60 127
    Start-Sleep -Milliseconds 120
    python midi\midi_serial.py -p $P --byte-gap 320 panic
    Start-Sleep -Milliseconds 500
}
```

**单条事件 + 指定音高/力度（改参数即可）**

```powershell
python midi\midi_serial.py -p $P --byte-gap 320 note 72 127     # C5、最响
python midi\midi_serial.py -p $P --byte-gap 320 note 48 64      # C3、中等
```

**测点对照（触发源与观测点）**

| 测点 | 引脚 | 信号 |
|---|---|---|
| MIDI 输入 | C21（乐器口）/ A17（混音口） | 31250 8N1，可直接当触发源 |
| 音频输出（推荐） | C24（PMOD1_IO0） | `sample_l` 的 1 位 SD 调制 → 需 RC（1k+10nF）还原模拟音频 |
| 声部层 | E25（PMOD1_IO1） | `voice_aud` 8 泳道求和 |
| DDS 输出 | L17（PMOD1_IO2） | 泳道 0 的 DDS 波形 |
