# 第四部分：决策记录与问答

## 4.5 音色库与音色映射

> 你的原话：「音色库我的想法是包含若干基础音色（远远小于128个），但可以选自己做的音色（但是还得从128个索引来接吧？是不是你之前说到的音色映射问题？）」

**是的，正是音色映射问题。** 而且你的需求（基础音色 + 自定义音色）**恰好说明了为什么需要 `bank`**：

```
MIDI 寻址空间 = bank(0–16383) × program(0–127)
                          ↑
                    正好用来区分「音色集合」
```

**方案建议：用 bank 分层**

| 库号 | 用途 | 说明 |
|---|---|---|
| `bank_msb = 0` | **基础音色库** | 映射到 GM 兼容位置（GM 里 program 0 = Acoustic Grand Piano） |
| `bank_msb = 1` | **自定义音色库** | 你自己做的音色，位置随意 |

如果**不在乎 GM 兼容**（不打算播放标准 MIDI 文件），也可以只用一个库、位置随意排 —— 但**映射表仍然需要**，因为你的音色数（16/32/64）与 program 编号（128）数量级不同。

**映射表形态：**

```
map[bank_msb][program] → timbre_slot      // 只读
```

**关于「起步方案」：** 之前提的恒等映射（槽号 = program）**在「基础音色要兼容 GM」的前提下不成立**——恒等映射意味着槽 0 必须是钢琴，而你有大量自定义音色。所以：

- **若做 GM 兼容**：需要真映射表（基础音色映射到 GM 位置，自定义音色放自定义库）
- **若不做 GM 兼容**：恒等映射可行（program 直接当槽号），最省逻辑

按你「暂不考虑拓展方案」的意见，本稿按**恒等映射**记录，但保留映射表的接口。

# 附录：待决策项汇总

## A.1 已决策

| 项 | 结论 |
|---|---|
| Program Change 切换语义 | **新音起效**（GM2 规范明文要求） |
| 通道表 `timbre_slot` | **移除**（派生值，只存声部表） |
| 声部表 `state` | **移除**（与 `env_state` 重复） |
| 声部表 `pan_gL/pan_gR/bend_ratio/vibrato_depth/timbre_gain` | **移除**（可由通道表 / 音色表直读） |
| 音色表 `pan_default` | **移除**（声像全交混音器） |
| 音色表 `send_*` | **移至通道表**（CC91/93/94 为通道级） |
| 通道表 `soft_pedal` | **移除**（与通道音量重复、使用率低） |
| 混音调节归属 | **外部混音设备**；乐器端混音消息忽略 |
| 效果器运算位置 | **必须在 FPGA 内** |
| 混音设备接口 | **独立新接口**（不与乐器接口共用） |
| 效果 / 主输出参数可变性 | **B 档**（可运行时改，经 SysEx / 上位机 / 蓝牙） |
| 声部数扩展方式 | **固定 `P`，只加 `G`** |
| `P` / `G` 初值 | **`P = 8`、`G = 4`**（32 声部起步；DSP 占用 36%、时间占用 7.8%） |
| 主时钟 | **`f_clk = 49.152 MHz`**（MS5351 供 **24.576 MHz**，FPGA PLL **×2**） |
| `USR_CLK_IN` 引脚 / 能否作 PLL | **`N22`**（来源 = MS5351 U2 的 `CLK2`，mux 档位 3）；**可作 PLL CLKIN** |
| I2S 位宽 / 格式 | **16 bit / LSBJ**（板载 DAC 为 PT8211） |
| 跳过空闲声部轮询 | **暂缓**（会引入抖动） |
| 时钟域架构 | **单一主时钟 + clock enable**（内部无 CDC） |
| 复位方式 | **异步复位、同步释放** |
| 定点格式 | **音频 Q1.23 / 系数 Q1.15**（见 `硬件实现.md` §五） |
| 表读写冲突 | **待写缓冲 + 采样边界提交**；效果/主输出表双缓冲（见 `硬件实现.md` §七） |
| 输出时钟生成 | **普通寄存器输出**（不用 ODDR / BUFG） |
| `pa_en`（H17）极性 | **Pro 板高电平有效**（Dock 板相反） |
