## 相对 baseline_G 的改动

1. **频谱显示**（`rtl/vis/spec_band.v` 新增 + `vis_top.v` / `wave_render.v` 改动）
   屏幕底部画 32 根对数频带柱（60 Hz ~ 16 kHz）；计算在音频域 clk_sys，渲染复用像素域
2. **`soft_limiter.v` 复位时序修复**（本轮的关键时序修复）
   · 问题：66 个 Setup 违例、最差 **−1.57 ns**，全部是
     `rst_sync_*_s0/Q → u_lim/env_d1_*_s0/D`
   · 根因：`rst_n` 是全局高扇出网络，而 PRIMARY/LW 已 8/8 用满（时钟资源墙），
     只能走通用布线，到限幅器 200+ 个 FF 的连线长达 21.9 ns > 周期 20.345 ns
   · 修法：模块内**再做 2 级复位同步**（`rst_n_l` 只在模块内扇出）+
     模块内 6 个 always 块改成**同步复位**（敏感表只留 `posedge clk`）
   · 行为差异：复位释放晚 2 拍（< 41 ns），音频算法一行未改
3. 波表槽 4 = Pad、槽 5 = 铜管 A（int16 补码，8 槽自检通过）
4. `voice_fetch.v`：`vg_of()` 每音色输出增益（槽4=31975、槽5=61536，其余 32768）
5. 三个诊断脚：**A20** 心跳 11.7 Hz / **A19** 音符门控 / **B21** 出声探针
